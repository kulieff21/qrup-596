Hər termin aid olduğu mühazirənin altında, mühazirədə göründüyü sıra ilə verilib. İzahlar qısadır: imtahan cavabında termini tanıtmaq üçün bir cümlə kifayətdir, ətraflı izah həmin mühazirənin Orta və Uzun səhifələrindədir.

## Mühazirə 1: Akademik yazının mahiyyəti, əsas xüsusiyyətləri və elmi üslubun prinsipləri

:::terms
[[term]]
name = "Akademik yazı"
full = "academic writing"
def = "Tədqiqat aparmağı, arqumentlərlə sübut etməyi və obyektiv mövqeyə əsaslanmağı tələb edən, analitik yanaşmalı yazı forması."

[[term]]
name = "Akademik savadlılıq"
def = "Mətnin formalaşdırılması, yazılması, müzakirəsi və təkrar işlənməsi prosesində inkişaf edən tənqidi düşünmə və yazılı ifadə səriştələri."

[[term]]
name = "İlkin janrlar"
def = "Elmi məqalə, dissertasiya, akademik icmal və monoqrafiya."

[[term]]
name = "İkinci dərəcəli janrlar"
def = "Elmi layihənin təsviri, tezis və müəllif referatı, elmi müzakirə, ensiklopedik məqalə, annotasiya."

[[term]]
name = "Elmi-publisistik janr"
def = "Geniş ictimai arenada ekspert rəylərini dərc etmək üçün istifadə olunan populyar elm sahəsi."

[[term]]
name = "Hədəf auditoriya"
def = "Mətnin ünvanlandığı oxucular: elmi ictimaiyyət, sahə tədqiqatçıları, akademik ekspertlər və rəyçilər."

[[term]]
name = "Rəyçi"
full = "peer reviewer"
def = "Akademik mətni elmi baxımdan qiymətləndirən ekspert; hədəf auditoriyanın tərkib hissəsi."

[[term]]
name = "Oxucu mövqeyinə hörmət"
def = "İddiaların kor-koranə təlqin edilməməsi, obyektiv dəlil, empirik fakt və etibarlı mənbələrlə əsaslandırılması prinsipi."

[[term]]
name = "Akademik mətnin strukturu"
def = "Giriş, əsas hissə və nəticədən ibarət sadə model; nəticədə yeni məlumat verilmir."

[[term]]
name = "Topic sentence"
def = "Abzasın əsas ideyasını ifadə edən cümlə; hər abzas yalnız bir əsas ideyaya fokuslanır."

[[term]]
name = "Mətnin bütövlüyü"
full = "cohesion and coherence"
def = "İdeyaların, abzasların və alt başlıqların sistemli əlaqələndirilməsi ilə yaranan mətn bütövlüyü."

[[term]]
name = "Ədəbiyyat icmalı"
full = "literature review"
def = "Mövcud tədqiqatları müqayisəli təhlil edib elmi boşluğu müəyyən edən və işin onu necə dolduracağını əsaslandıran bölmə."

[[term]]
name = "Terminoloji dəqiqlik"
def = "Hər terminin konkret və sabit mənası olması; bir anlayış üçün bir termin prinsipi."

[[term]]
name = "Obyektivlik"
def = "Müəllifin şəxsi münasibət və emosiyadan uzaq durub məlumatı faktlara əsasən şərh etməsi."

[[term]]
name = "Tərəfsizlik"
def = "Müxtəlif baxış bucaqlarına bərabər məsafədə durmaq, əks mövqeləri nəzərə almaq və yalnız elmi əsaslara söykənmək."

[[term]]
name = "Akademik leksika"
full = "Academic Word List (AWL)"
def = "Ümumi işlək sözlər əvəzinə işlədilən, fikri dəqiq və elmi tutumlu ifadə edən analitik funksiyalı söz ehtiyatı."

[[term]]
name = "Tautologiya"
def = "Yersiz söz və ya fikir təkrarı; akademik leksik zənginlik onun qarşısını alır."

[[term]]
name = "Denotativ məna"
def = "Sözün birbaşa mənası; akademik yazıda yalnız bu mənada işlədilir."

[[term]]
name = "Konnotasiya"
def = "Sözün məcazi və ya emosional mənası; akademik yazıda qaçınılır."

[[term]]
name = "Məchul növ"
def = "Diqqəti icraçıdan prosesə və nəticəyə yönəldən quruluş: «temperatur artırılmışdır»; həddindən artıq işlədilməməlidir."

[[term]]
name = "Yumşaldıcı ifadələr"
def = "Ehtimal bildirən ifadələr (görünür, ehtimal olunur, göstərə bilər); şəxsi əvəzliklər əvəzinə mövqeyi bildirir."
:::

## Mühazirə 2: Akademik yazıda arqumentasiya, tənqidi təfəkkür və məntiqi ardıcıllıq

:::terms
[[term]]
name = "Arqumentasiya"
full = "argumentation"
def = "Aydın mövqenin (tezisin) etibarlı sübutlarla dəstəklənən, məntiqi qurulmuş arqumentlərlə əsaslandırılması; akademik yazının ürəyi."

[[term]]
name = "Tənqidi təfəkkür"
full = "critical thinking"
def = "Məlumatın fəal dərk edilməsi, tətbiqi, təhlili, sintezi və qiymətləndirilməsinin intellektual intizamlı, özünü tənzimləyən prosesi."

[[term]]
name = "Akademik arqument"
def = "Oxucunu rasional əsaslandırma ilə inandırmaq üçün təqdim edilən, ardıcıl səbəblərlə və mötəbər sübutlarla dəstəklənən tutarlı iddia."

[[term]]
name = "Tezis"
full = "claim"
def = "Müəllifin mətn boyu sübut etməyə çalışdığı mərkəzi fikir; adətən girişin sonunda aydın və qısa verilir."

[[term]]
name = "Səbəblər"
full = "reasons"
def = "Tezisə birbaşa dəstək verən izahatlar və ya alt iddialar; “niyə?” sualına cavab verir."

[[term]]
name = "Sübut"
full = "evidence"
def = "İddianı dəstəkləyən xüsusi, yoxlanıla bilən məlumat: fakt, statistika, empirik nəticə, mötəbər sitat, misal."

[[term]]
name = "Deduktiv arqument"
def = "Ümumi mülahizələrdən xüsusi nəticə çıxarır (ümumidən xüsusiyə); müddəalar doğru və struktur etibarlıdırsa, nəticə mütləq doğrudur."

[[term]]
name = "İnduktiv arqument"
def = "Xüsusi hallar üzrə müşahidələrdən ümumi nəticə çıxarır (xüsusidən ümumiyə); nəticə zərurət deyil, ehtimal səviyyəsindədir."

[[term]]
name = "Abduktiv arqument"
full = "inference to the best explanation"
def = "Müşahidə olunan faktlar üçün ən inandırıcı izahatı axtarır; tədqiqatın ilkin mərhələsində fərziyyə formalaşdırmağa xidmət edir."

[[term]]
name = "Loqos"
full = "logos"
def = "Sübutlarla dəstəklənən, oxucunun məntiqinə və ağlına müraciət; akademik yazıda mərkəzi yer tutur."

[[term]]
name = "Etos"
full = "ethos"
def = "Müəllifin nüfuzu və etibarlılığı; akademik yazıda diqqətli araşdırma və mənbələrdən dəqiq sitat gətirmə ilə qurulur."

[[term]]
name = "Pafos"
full = "pathos"
def = "Auditoriyanın emosiya və dəyərlərinə müraciət; akademik yazıda problemin aktuallığı və əhəmiyyəti ilə nümayiş olunur."

[[term]]
name = "Özünütənzimləmə"
full = "meta-cognition"
def = "Öz düşüncə prosesini izləmək, öz fərziyyə və qərəzləri üzərində düşünmək və lazım gəldikdə yanaşmanı dəyişmək bacarığı."

[[term]]
name = "CRAAPO"
full = "Currency, Relevance, Authority, Accuracy, Purpose, Objectivity"
def = "Mənbənin tənqidi qiymətləndirilməsi meyarları: aktuallıq, uyğunluq, nüfuz, dəqiqlik, məqsəd, obyektivlik."

[[term]]
name = "Arqumentativlik"
full = "argumentativeness"
def = "Tezisin razılaşdırıla və ya razılaşdırılmaya bilən, sübut tələb edən bəyanat olması; məlum fakt və ya subyektiv fikir deyil."

[[term]]
name = "İşçi tezis"
full = "working thesis"
def = "Tədqiqat dərinləşdikcə dəqiqləşdirilən və dəyişdirilən ilkin tezis variantı."

[[term]]
name = "Toulmin modeli"
def = "Arqumentin mikro strukturunu üç elementlə göstərən çərçivə: iddia, məlumat (sübut) və əsaslandırma."

[[term]]
name = "Əsaslandırma"
full = "warrant"
def = "Sübutun nə üçün iddianı dəstəklədiyini izah edən məntiqi əlaqə və ya prinsip; çox vaxt gizli qalır, açıq yazılmalıdır."

[[term]]
name = "Tematik cümlə"
full = "topic sentence"
def = "Abzasın əsas ideyasını ifadə edən və mətnin ümumi tezisinə bağlanan cümlə."

[[term]]
name = "MEAL"
full = "Main idea, Evidence, Analysis, Link"
def = "Abzas modeli: əsas fikir, sübut, təhlil/izahat, yekun və ya keçid cümləsi."

[[term]]
name = "Keçid sözləri"
full = "transition words"
def = "Fikirlər, cümlələr və abzaslar arasındakı məntiqi əlaqəni göstərən “yol nişanları” (lakin, ona görə də, məsələn, beləliklə)."

[[term]]
name = "Tutarlılıq və birlik"
full = "coherence and cohesion"
def = "Mətnin məzmunca ardıcıllığı və hissələrinin bir-birinə bağlılığı; keçid sözlərinin düzgün işlənməsi onu gücləndirir."
:::

## Mühazirə 3: Elmi esse, referat, tezis və xülasənin yazılma texnikası

:::terms
[[term]]
name = "Elmi esse"
def = "Müəllifin problemə dair nəzəri arqumentasiya və empirik dəlillərə söykənən, əsaslandırılmış fərdi mövqeyini əks etdirən akademik janr."

[[term]]
name = "Esse strukturu"
def = "Başlıq, giriş, əsas hissə, nəticə və istinadlar (ədəbiyyat) siyahısı; mühazirə \"dörd komponent\" deyir, lakin beşini sadalayır."

[[term]]
name = "Arqumentasiya modeli"
def = "Essedə arqumentlərin qurulma ardıcıllığı: İdeya, Arqument, Sübut (empirik baza), Nəticə (yekun qənaət)."

[[term]]
name = "Referat"
full = "lat. referre – məruzə etmək, xəbər vermək"
def = "Milli və xarici ədəbiyyatın araşdırılıb sistemləşdirilməsi və obyektiv ümumiləşdirilməsi əsasında hazırlanan hesabat xarakterli yazı."

[[term]]
name = "Akademik bələdçi"
def = "Referat müəllifinin rolu: öz mövqeyini irəli sürmür, fərqli alim və məktəblərin yanaşmalarını bitərəf təsvir və sistemləşdirir."

[[term]]
name = "Titul vərəqi"
def = "Referatın rəsmi \"pasportu\": təhsil müəssisəsinin adı, kafedra, mövzu, icraçı və elmi rəhbər."

[[term]]
name = "Retrospektiv xarakter"
def = "Referatın xüsusiyyəti: mövcud biliyin toplanması, çeşidlənməsi və strukturlaşdırılmış icmalının yaradılması."

[[term]]
name = "Tezis"
full = "yun. thesis"
def = "Tədqiqatın ana xəttini, ideyalarını və nəticələrini yığcam, informasiya tutumlu formada təqdim edən janr; \"elmi kvintessensiya\"."

[[term]]
name = "Açar sözlər"
def = "Tezisdə tədqiqatın semantik nüvəsini təşkil edən və indeksləşdirmə üçün zəruri olan 4–6 termin."

[[term]]
name = "Tədqiqat boşluğu"
full = "gap"
def = "Mövcud tədqiqatlarda çatışmayan cəhət; tezisin girişində problemin qoyuluşu və aktuallığın əsası kimi bəyan edilir."

[[term]]
name = "Annotasiya"
full = "lat. annotatio – qeyd, xülasə"
def = "Əsər, məqalə və ya dissertasiya haqqında ümumi məlumat verən ultra-yığcam təsviri mətn; bitmiş əsərin metadata hissəsi."

[[term]]
name = "Xülasə"
full = "Summary, Précis"
def = "Geniş mətnin əsas məzmununu, ana ideyasını və arqumentlərini məntiqi ardıcıllıqla maksimum qısa şəkildə yenidən formalaşdırma prosesi."

[[term]]
name = "Redundansiya"
def = "Mətndəki təkrarlanan, ikinci dərəcəli və köməkçi informasiya; xülasədə məqsədyönlü şəkildə xaric edilir."

[[term]]
name = "Mexaniki qısaltma"
def = "Hər abzasdan bəzi cümlələri kəsib saxlamaq; xülasə yazarkən ən böyük metodoloji xəta sayılır."

[[term]]
name = "Koherentlik"
def = "Xülasədə ixtisar olunmuş fikirlər arasında keçidlər və məntiqi bağlarla qurulan ardıcıllıq və bütövlük."

[[term]]
name = "Hermenevtik oxu"
def = "Xülasənin birinci mərhələsi: mətnin mahiyyətini, kontekstini və müəllif intonasiyasını qavramaq üçün dərindən, analitik oxunması."

[[term]]
name = "Miniatür surət"
def = "Xülasənin xarakteristikası: mətnin içindəkilərin makro-struktur səviyyəsində qısa yenidən istehsalı."

[[term]]
name = "Annotasiya \"pasportu\""
def = "Annotasiyanın xarakteristikası: əsərin detallarını açmayan, mövzu, məqsəd və metodlar barədə anons verən bələdçi."

[[term]]
name = "İlkin və ikinci dərəcəli janrlar"
def = "İlkin: məqalə, dissertasiya, icmal, monoqrafiya. İkinci dərəcəli: layihə təsviri, tezis, müəllif referatı, müzakirə, ensiklopedik məqalə, annotasiya."

[[term]]
name = "Neytrallıq"
def = "Şəxsi fikirlərə, emosional ifadələrə və subyektiv qiymətləndirmələrə yer verməmək; obyektivliyin tərkib hissəsi."
:::

## Mühazirə 4: Elmi məqalənin strukturu və yazılma texnikası

:::terms
[[term]]
name = "Elmi məqalə"
def = "Tədqiqat nəticələrinin sistemli, obyektiv və elmi standartlara uyğun təqdim olunduğu yazı forması."

[[term]]
name = "Tərtib (icmal) məqaləsi"
def = "Konkret sahədə əvvəlki tədqiqatların nəticələrini sistemli ümumiləşdirən, boşluqları və gələcək istiqamətləri göstərən məqalə növü."

[[term]]
name = "Başlıq"
full = "Title"
def = "Tədqiqatın məzmununu qısa (adətən 10–12 söz), aydın, neytral və deskriptiv əks etdirən ifadə."

[[term]]
name = "Xülasə"
full = "Abstract"
def = "Məqsədi, metodologiyanı, əsas nəticələri və qənaətləri ardıcıl verən, müstəqil oxunan qısa mətn (ənənəvi 150–300 söz)."

[[term]]
name = "Açar sözlər"
full = "Keywords"
def = "Məqalənin əsas anlayışlarını əks etdirən 3–6 spesifik termin; indekslənmə və axtarışda tapılma üçün istifadə olunur."

[[term]]
name = "İndekslənmə"
def = "Məqalənin elmi məlumat bazalarında sistemləşdirilməsi və axtarışda asan tapılması."

[[term]]
name = "IMRaD"
full = "Introduction, Methods, Results, and Discussion"
def = "Məqalənin əsas hissəsinin beynəlxalq qəbul edilmiş modeli: Giriş, Metodologiya, Nəticələr, Müzakirə."

[[term]]
name = "Giriş"
full = "Introduction"
def = "Mövzunu, aktuallığı və ədəbiyyatdakı boşluğu göstərir; məqsəd, sual və ya hipotezlə yekunlaşır."

[[term]]
name = "Metodologiya"
full = "Methodology"
def = "Tədqiqatın necə aparıldığını izah edən bölmə: yanaşma, məlumat toplama, nümunə, təhlil; keçmiş zamanda yazılır."

[[term]]
name = "Metodoloji şəffaflıq"
def = "Metodların aydın təsviri; nəticələrin təkrar istehsal edilə bilməsi və etibarlılığı üçün vacibdir."

[[term]]
name = "Nəticələr"
full = "Results"
def = "Tapıntıların statistika, qrafik və cədvəllə şərhsiz, obyektiv təqdim olunduğu bölmə."

[[term]]
name = "Müzakirə"
full = "Discussion"
def = "Nəticələrin təhlil, izah və əvvəlki tədqiqatlarla müqayisə olunduğu, məhdudiyyətlərin göstərildiyi bölmə."

[[term]]
name = "Məhdudiyyətlər"
def = "Tədqiqatın nəticələrin ümumiləşdirilməsinə təsir edən məhdud cəhətləri; açıq etiraf etmək şəffaflıq göstəricisidir."

[[term]]
name = "Nəticə və Təkliflər"
full = "Conclusion"
def = "Məqsədə çatılıb-çatılmadığını qiymətləndirən, praktik və nəzəri əhəmiyyəti və gələcək tədqiqat istiqamətlərini göstərən yekun bölmə."

[[term]]
name = "Qoşma məktub"
def = "Məqaləni jurnala təqdim edərkən redaktorlara göndərilən, əsas ideya, aktuallıq və yeniliyi vurğulayan qısa yazı."

[[term]]
name = "Rəy prosesi"
def = "Müstəqil rəyçilərin məqalənin etibarlılığını, metodoloji düzgünlüyünü və aydınlığını qiymətləndirməsi."

[[term]]
name = "Plagiat"
def = "Başqasının fikrini, nəticəsini və ya mətnini istinad etmədən təqdim etmək; ciddi elmi pozuntu."
:::

## Mühazirə 5: Yazı prosesinin təşkili: ideyaların yaradılması və mətnin strukturlaşdırılması

:::terms
[[term]]
name = "Rekursiv yazı prosesi"
def = "Yazının mərhələlər arasında dövri qayıdışlarla irəlilədiyi model: oxu arqumenti, arqument strukturu və tezisi yenidən nəzərdən keçirməyə vadar edir."

[[term]]
name = "Xətti model"
def = "Məlumat toplama → plan → yazı → redaktə ardıcıllığını geri qayıtmadan keçən model; başlanğıc müəlliflər üçün əlverişlidir, real təcrübəni zəif əks etdirir."

[[term]]
name = "Planlaşdırma"
full = "pre-writing"
def = "Yazı prosesinin ilk mərhələsi: ideyaların toplanması, nizamlanması və planın hazırlanması."

[[term]]
name = "Qaralama"
full = "drafting"
def = "Qaralama variantın tərtib edilməsi mərhələsi; qaralama yekun mətn deyil, düşüncə üçün işçi alətdir."

[[term]]
name = "Yenidən işləmə"
full = "revising"
def = "Mətnin yenidən işlənməsi mərhələsi; qaralamanın məzmun, struktur və arqument baxımından təkmilləşdirilməsi."

[[term]]
name = "Beyin fırtınası"
full = "brainstorming"
def = "Mövzu ilə bağlı ideyaların əvvəlcədən qiymət vermədən sərbəst qeyd edilməsi; məqsəd keyfiyyət deyil, kəmiyyətdir."

[[term]]
name = "Sərbəst yazı"
full = "freewriting"
def = "Orfoqrafiya və üslub səhvlərinə dayanmadan müəyyən vaxt ərzində fasiləsiz yazı; daxili «senzoru» aşmağa kömək edir."

[[term]]
name = "Klaster / ideya xəritəsi"
full = "mind-mapping"

## Mühazirə 6: Mənbələrlə iş: parafraz, ədəbiyyat icmalı və tənqidi təhlil

:::terms
[[term]]
name = "Primer mənbə"
full = "primary source"
def = "Tədqiqatın özünü və ya hadisənin birbaşa sübutunu verən mənbə: orijinal məqalə, eksperiment, rəsmi statistika, arxiv sənədi, müsahibə."

[[term]]
name = "Sekundar mənbə"
full = "secondary source"
def = "Primer mənbələri şərh edən, ümumiləşdirən və ya təhlil edən mənbə: icmal məqalə, monoqrafiya, dərslik."

[[term]]
name = "Tersiar mənbə"
full = "tertiary source"
def = "Mövcud biliyi toplayan mənbə: ensiklopediya, məlumat kitabçası, indeks. Yalnız ümumi məlumat və istiqamət üçündür."

[[term]]
name = "Anlayış cədvəli"
def = "Hər sütunda bir əsas anlayışın açar sözləri, sinonimləri və ingiliscə qarşılıqları toplanan cədvəl; axtarış sorğusunun əsasıdır."

[[term]]
name = "Bul operatorları"
full = "Boolean operators"
def = "AND (daraldır), OR (genişləndirir), NOT (çıxarır); dırnaq, ulduz və mötərizə ilə axtarış sorğusunu qurur."

[[term]]
name = "Mənbə zənciri"
full = "citation chaining, snowballing"
def = "Tapılmış yaxşı mənbələrdən istinad əlaqələri ilə yeni mənbələr aşkar etmə üsulu: geriyə (ədəbiyyat siyahısı) və irəliyə (“Cited by”)."

[[term]]
name = "CRAAP testi"
full = "Currency, Relevance, Authority, Accuracy, Purpose"
def = "Mənbənin ilkin süzgəci: aktuallıq, uyğunluq, səlahiyyət, dəqiqlik, məqsəd. Meyarların çəkisi sahədən asılıdır."

[[term]]
name = "Şübhəli (predator) jurnal"
full = "predatory journal"
def = "Real hakemlik aparmadan ödəniş müqabilində məqalə dərc edən jurnal; “Think. Check. Submit.” tövsiyələri ilə tanınır."

[[term]]
name = "İmpakt faktor"
full = "impact factor"
def = "Jurnalın orta istinad səviyyəsini göstərir; ayrıca məqalənin keyfiyyətini göstərmir."

[[term]]
name = "Üç keçidli oxu"
full = "three-pass approach"
def = "Məqalənin üç mərhələdə oxunması: skim (5–10 dəq.), anlamaq, tənqidi oxu (yalnız vacib mənbələr üçün)."

[[term]]
name = "Sintez matrisi"
full = "synthesis matrix"
def = "Mənbələrin sətirlərdə, meyarların (məqsəd, metod, nümunə, nəticə, məhdudiyyət, aidiyyat) sütunlarda yazıldığı təhlil cədvəli (Webster və Watson)."

[[term]]
name = "Analitik qeyd"
def = "Mənbənin sualıma aidiyyatını, güclü və zəif tərəflərini, digər mənbələrlə əlaqəsini göstərən qeyd; icmalın əsasıdır."

[[term]]
name = "Dəstək"
full = "backing"
def = "Tulmin modelinə mühazirədə əlavə olunan element: əsaslandırmanın özünü təsdiqləyən mənbə və ya nəzəriyyə."

[[term]]
name = "Mozaika parafraz"
full = "patchwriting"
def = "Yalnız bir neçə sözün sinonimlə əvəzlənməsi; mənbənin quruluşu saxlanır, plagiat riski yaranır."

[[term]]
name = "Parafraz"
full = "paraphrase"
def = "Konkret fikrin mənası saxlanmaqla öz sözlərinlə və öz cümlə quruluşunla ifadə olunması."

[[term]]
name = "Xülasə"
full = "summary"
def = "Bütöv mənbənin və ya böyük hissənin əsas fikrinin qısa verilməsi; abstraktdan (müəllifin öz məqaləsi üçün yazdığı məzmun) fərqlənir."

[[term]]
name = "İstinad edən fellər"
full = "reporting verbs"
def = "Başqasının fikrini təqdim edən fellər (qeyd edir, iddia edir, təklif edir, şübhə altına alır); mənbənin dediyinə uyğun seçilməlidir."

[[term]]
name = "Ədəbiyyat icmalı"
full = "literature review"
def = "Mövzu üzrə tədqiqatların sistemli təhlili, qiymətləndirilməsi və sintezi; mənbə siyahısı deyil."

[[term]]
name = "PRISMA"
full = "Preferred Reporting Items for Systematic Reviews and Meta-Analyses"

[[term]]
name = "Huni quruluşu"

## Mühazirə 7: İstinad sistemləri və biblioqrafiyanın tərtibi qaydaları

:::terms
[[term]]
name = "İstinad"
def = "Başqa müəllifə məxsus ideya, məlumat, nəticə və ya mətnin mənbəyinin göstərilməsi."

[[term]]
name = "İstinad standartı"
full = "citation style"

name = "Mətnə daxil edilmiş istinad"

[[term]]

[[term]]

[[term]]
name = "Rəqəmli sistem"
def = "Mətndə kvadrat mötərizədə nömrə verilən, siyahısı ilk istinad sırası ilə düzülən sistem (IEEE, Vancouver)."

[[term]]

full = "footnote / notes–bibliography"

[[term]]
name = "Biblioqrafiya"

[[term]]
name = "Annotasiyalı biblioqrafiya"
