Akademik yazı çox vaxt artıq hazır olan fikrin kağıza köçürülməsi kimi qəbul edilir. Mühazirənin əsas fikri bunun əksinədir: keyfiyyətli elmi mətn bir dəfəlik hərəkət deyil, geniş həcmli, idarə olunan və rekursiv prosesin nəticəsidir. Bu proses ideyaların yaranmasını, seçilməsini, işçi fərziyyə və tezisin formalaşmasını, gələcək işin məntiqi arxitekturasının qurulmasını əhatə edir. Yazını məhsul kimi yox, proses kimi anlamaq qaralamaya münasibəti dəyişir: qaralama yekun mətn deyil, düşüncə üçün işçi alətdir.

Mövzu üç sahəyə bölünür: yazı prosesinin idarəsi və ideyaların generasiyası; fərziyyə və tezis; mətnin strukturu, giriş və nəticə.

## Yazı prosesinin idarə edilməsi və ideyaların generasiyası

### Mərhələlər və modellər

Akademik yazı prosesi ənənəvi olaraq üç mərhələ ilə təsvir olunur: **planlaşdırma** (pre-writing), **qaralama variantın tərtibi** (drafting) və **mətnin yenidən işlənməsi** (revising). Bu mərhələlər bir-birini ciddi xətti qaydada izləmir. Təcrübəli müəllif mətnin yazılmasından planın yenidən düşünülməsinə, redaktədən əlavə material toplamağa qayıdır. Bu rekursivlik yetkin yazı təcrübəsinin əsas əlamətidir.

| | Xətti model | Rekursiv model |
| --- | --- | --- |
| Ardıcıllıq | Məlumatın toplanması → planın tərtibi → yazılma → redaktə, əvvəlki addımlara qayıtmadan | Yazı dövri prosesdir: mərhələlər arasında dəfələrlə qayıdış var |
| Nümunə | – | Tezisin eskizi əlavə oxu tələb edir; oxu arqumentləri dəqiqləşdirir; bu, strukturun və hətta tezisin yenidən baxışına gətirir |
| Güclü tərəf | Başlanğıc müəlliflər üçün anlaşılan hərəkət alqoritmi verir | Elmi yazının real təcrübəsini əks etdirir |
| Zəif tərəf | Real təcrübəni zəif əks etdirir, çünki mövzunun anlaşılması yazı prosesində dərinləşir | – |

Prosesin qeyri-xəttiliyini dərk etmək başlanğıc tədqiqatçının «kamil olmayan» qaralama qarşısındakı narahatlığını azaldır və yenidən yazmağı uğursuzluq yox, işin təbii mərhələsi kimi qəbul etməyə imkan verir.

### İdeyaların generasiyası texnikaları

Tezisin formalaşdırılmasına başlamazdan əvvəl müəllif ilkin materialı toplamalı və nizamlamalıdır. Akademik təcrübədə bunun üçün 5 sınanmış texnika var:

:::terms İdeya texnikaları
[[term]]
name = "Beyin fırtınası"
full = "brainstorming"
def = "Mövzu ilə bağlı bütün ideyaların, assosiasiyaların və sualların keyfiyyətinə əvvəlcədən qiymət vermədən sərbəst qeyd edilməsi. Məqsəd kəmiyyətdir; tənqidi qiymətləndirmə sonrakı mərhələyə saxlanılır."

[[term]]
name = "Sərbəst yazı"
full = "freewriting"
def = "Orfoqrafiya, üslub və ya səhvlərin düzəlişinə dayanmadan müəyyən vaxt ərzində (məsələn, 10 dəqiqə) fasiləsiz yazı. Daxili «senzoru» aşmağa kömək edir və arqumentin əsasını təşkil edə biləcək gözlənilməz fikir dönüşlərini üzə çıxarır."

[[term]]
name = "Klaster / ideya xəritəsi"
full = "mind-mapping"
def = "Mövzunun mərkəzi anlayış və ondan yaranan əlaqəli alt mövzu və arqumentlər şəklində vizual təqdimatı. İdeyalar arasındakı əlaqələri aşkar etmək və sonradan mətnin məntiqi strukturunu qurmaq üçün xüsusilə faydalıdır."

[[term]]
name = "Sual metodu"
full = "5W1H"
def = "«Nə? kim? nə vaxt? harada? niyə? necə?» suallarının ardıcıl qoyulması. Problemin müxtəlif tərəflərini sistemli əhatə etməyə və daha dərin araşdırma tələb edən aspektləri müəyyən etməyə imkan verir."

[[term]]
name = "Açar sözlər siyahısı və ilkin oxu"
def = "Mövzuya aid terminlərin siyahısı və bir neçə mənbənin səthi icmalı. İşçi fərziyyəyə keçməzdən əvvəl tədqiqat sahəsinin sərhədlərini müəyyən etməyə kömək edir."
:::

**Nümunə (mühazirədən).** Mövzu: «Məsafədən iş və əməyin məhsuldarlığı».

1. **Beyin fırtınası** dağınıq siyahı verir: «çevik iş qrafiki», «yol vaxtına qənaət», «komandada kommunikasiya çətinlikləri», «motivasiyanın azalması», «ofis sahələrinə qənaət».
2. **Klaster** siyahını 4 qola bölür: işçi üçün iqtisadi, işəgötürən üçün iqtisadi, psixoloji, təşkilati effektlər.
3. **5W1H** («Kim məhsuldarlıqda itirir? Niyə? Hansı şəraitdə məhsuldarlıq artır?») dairəni ən perspektivli istiqamətə daraldır.

Bu texnikaların heç biri özlüyündə məqsəd deyil: məhsulları sonradan tənqidi seçim və təşkilə məruz qalan «xam» materialdır.

:::tip Əlavə
Beyin fırtınası və sərbəst yazı **çox** ideya verir (kəmiyyət), klaster və 5W1H isə onları **nizamlayır və daraldır**. Cavabda «hansı texnika nə üçün» sualına belə cavab vermək cavabı güclü göstərir.
:::

### Süni intellektdən və rəqəmsal alətlərdən etik istifadə

Generativ alətlər ilkin mərhələdə (artıq toplanmış ideyaların işlənməsi, ifadələrin dəqiqləşdirilməsi) faydalı ola bilər, lakin akademik dürüstlük sualları doğurur (Gallant, 2023).

- **Bowen (2024):** vəzifə texnologiyanı qadağan etmək deyil, onun **şüurlu və şəffaf** tətbiqini formalaşdırmaqdır. Süni intellekt ideya yaranmasında «tərəfdaş» ola bilər, lakin tədqiqatçının tənqidi təhlilini və müəllif mövqeyini əvəz etməməlidir.
- **Gallant (2023):** diqqət «köçürməni tutmaq»dan «dürüstlüyə öyrətmək»ə yönəlməlidir.
- **Bergadaà və Peixoto (2024):** dürüstlüyün sərhədləri daim yenidən düşünülməlidir; mətni yenidən ifadə edən alqoritm kimi vasitələr boz zonadadır.
- **Praktik nəticə:** istifadə şəffaf olmalı, öz düşüncəni əvəz etməməli, ona əlavə olunmalı və təhsil müəssisəsinin tələblərinə zidd olmamalıdır.

### Vaxtın idarə edilməsi və yazıda «tutulma»

Vaxt idarəetməsi: böyük tapşırığı alt-tapşırıqlara bölmək (məsələn, «planın tərtibi — 30 dəqiqə»), aralıq son müddətlər qoymaq, mütəmadi və «hücumvari» olmayan rejimdə işləmək.

**Yazıda tutulma** (writer's block) müəllifin planlaşdırmadan mətnin yazılmasına keçə bilmədiyi vəziyyətdir. Tövsiyə olunan strategiyalar:

1. «Mükəmməl» ilk cümlə tələbindən müvəqqəti imtina edib sərbəst yazıya keçmək;
2. Mətni ardıcıllıqla yox, ən aydın görünən bölmədən başlayaraq yazmaq;
3. Fikir axınını bərpa etmək üçün qısa müddətə beyin fırtınasına qayıtmaq.

Qaralama öz təbiətinə görə kamil deyil; onun sonradan işlənməsi zəif hazırlığın əlaməti deyil, prosesin ayrılmaz hissəsidir.

## Fərziyyə və tezisin formalaşdırılması

İdeyalar yalnız onlar aydın məzmun mərkəzi, yəni sonradan tezisə çevrilən işçi fərziyyə ətrafında təşkil olunanda tədqiqat dəyəri qazanır. «İdeyalar buludu»ndan fokuslaşdırılmış müddəaya keçid yazı prosesinin ən çox intellektual gərginlik tələb edən mərhələsidir.

### Tədqiqat sualından işçi fərziyyəyə

Tədqiqatın başlanğıc nöqtəsi hazır cavab deyil, aydın formalaşdırılmış **tədqiqat sualıdır**. Yaxşı sual ayrılmış həcm çərçivəsində məzmunlu cavab vermək mümkün olacaq qədər **dar**, elmi diqqətə layiq olacaq qədər **əhəmiyyətli** olmalıdır (Bailey, 2018).

Sualın əsasında **işçi fərziyyə** qurulur: suala ehtimal olunan cavab və ya hadisələr arasındakı əlaqənin xarakteri haqqında yoxlanılmalı ilkin fərziyyə. Tezisdən fərqli olaraq fərziyyə:

- əsasən **empirik və eksperimental** tədqiqatlar üçün xarakterikdir;
- **ehtimalidir**: iş zamanı təsdiqlənə, korrektə edilə və ya təkzib oluna bilər.

UNEC-in dissertasiya qaydaları tədqiqatın məqsədi, fərziyyə və yekun nəticələr arasında aydın fərq qoyulmasını tələb edir.

### Tezisin təkamülü

Materiala dərindən girməzdən əvvəl tərtib edilən ilkin tezis forması **işçi tezis** adlanır. Onun funksiyası mövqeyi yekun olaraq təsbit etmək deyil, sonrakı oxu, təhlil və yazı üçün **istiqamət müəyyən etməkdir**. Yeni mənbələrlə tanış olduqca, baxışları müqayisə etdikcə və daha inandırıcı arqumentlər tapdıqca işçi tezis dəqiqləşir, daralır, hətta prinsipcə yenidən nəzərdən keçirilir (Graff və Birkenstein, 2021).

**They Say / I Say** modeli: inandırıcı tezis heç vaxt boşluqda formalaşmır. O, mövcud elmi söhbətə («they say») cavabdır; bu söhbət başqa tədqiqatçıların təsdiqlədiyi, şübhə altına aldığı və ya kifayət qədər öyrənilməmiş məsələlərdir. Tezisin bu dialoji təbiəti yetkin akademik mövqeyi («I say») əsassız, təcrid olunmuş müddəadan fərqləndirir.

Tövsiyə: tezisin aralıq variantlarını yazılı saxla və hər mühüm mərhələdən sonra ona qayıt; bu, dərkin dərinləşməsini izləməyə imkan verir.

:::exam
**Yoxlanıla bilənlik meyarı.** Fərziyyə elə formalaşdırılmalıdır ki, toplanan məlumatlar əsasında onun həm təsdiqlənməsi, həm də təkzib edilməsi prinsipcə mümkün olsun. Heç bir empirik məlumatla təkzib edilə bilməyən fərziyyə elmi əsas ola bilməz və adətən formulanın kifayət qədər konkret olmadığını göstərir.
:::

**Nümunə: mövzudan tezisə.**

| Pillə | Formul |
| --- | --- |
| Mövzu | Məsafədən iş və əməyin məhsuldarlığı |
| Tədqiqat sualı | Məsafədən işə keçid 2020–2024-cü illərdə Azərbaycanda xidmət sferası işçilərinin əmək məhsuldarlığına necə təsir göstərib? |
| İşçi fərziyyə | Məsafədən işə keçid məhsuldarlığa birmənalı olmayan təsir göstərir: yüksək özünütəşkilat səviyyəsi olan işçilər üçün müsbət, daim komanda koordinasiyası tələb edənlər üçün mənfi |
| Yekun tezis | Xidmət sferasında məsafədən işdə məhsuldarlığın azalması əsasən işçilər arasında üfüqi koordinasiyanın zəifləməsi ilə bağlıdır, halbuki muxtar tapşırıqlar yerinə yetirən mütəxəssislərin fərdi məhsuldarlığı artır |

### Fərqli iş növlərində nisbət

Tədqiqat sualı, fərziyyə və tezis arasındakı nisbət janrdan və elm sahəsindən asılıdır.

| İş növü | Fərziyyə və tezis |
| --- | --- |
| Analitik esse, ədəbiyyat icmalı | Bir qayda olaraq formal fərziyyə olmur; iş tezis ətrafında interpretasiya müddəası kimi qurulur |
| Empirik tədqiqat (eksperimental, statistik, sahə) | Əvvəlcə yoxlanılan fərziyyə qoyulur; yekun tezis onun təsdiqi və ya təkzibi nəticələrinə əsasən formalaşır |

Məmmədova, Qasımova və Əyyub (2014) qeyd edir ki, Azərbaycan akademik məkanında buraxılış və ya dissertasiya işinin girişində **məqsəd, vəzifələr, fərziyyə (əgər tətbiq olunursa) və müdafiəyə çıxarılan müddəa** (tezisin dar mənası) fərqləndirilir. Bu, rəyçilərə işin məntiqi bütövlüyünü girişdən qiymətləndirməyə kömək edir.

## Mətnin məntiqi strukturu, giriş və nəticənin xüsusiyyətləri

Tezis formalaşandan sonra əsas vəzifə arqumentlərin, sübutların və aralıq nəticələrin ardıcıllığını seçməkdir. Yaxşı struktur həm oxucu, həm müəllif üçün «yol xəritəsi»dir (McCormack və Slaght, 2012).

### Makro- və mikrostruktur

- **Makro səviyyə:** janrdan asılı olmayaraq giriş, əsas hissə və nəticə. APA (2020) bu sxemi empirik məqalələr üçün **IMRaD** (Introduction — Methods — Results — and Discussion) strukturu kimi konkretləşdirir; bu, təqdimatın vahidliyini və proqnozlaşdırıla bilənliyini təmin edir.
- **Prinsip:** struktur tədqiqat prosesinin **xronologiyasını** deyil, **arqumentasiyanın inkişaf məntiqini** əks etdirməlidir. Ardıcıllığı müəllifin materialı toplama sırası yox, oxucunu tezisin qəbuluna ən inandırıcı yolla yönəltmək müəyyən edir.
- **Mikro səviyyə:** ayrı-ayrı abzasların quruluşu və aralarındakı məntiqi bağlar (3-cü mühazirədə MEAL modeli: əsas fikir — sübutlar — təhlil — bağlantı).
- Makro və mikro uzlaşdırılmalıdır: işin ümumi məntiqi hər bölmənin və abzasın inkişafında izlənməlidir.

### Girişin funksiyaları və strukturu

Giriş 4 funksiya yerinə yetirir: diqqəti mövzuya cəlb edir, kontekst verir, problemi və ya biliklərdəki boşluğu göstərir, tezisi təqdim edir. Ən geniş yayılmış model **«qıf»dır** (funnel structure): təqdimat ümumi kontekstdən daralan konkret probleməcən gedir və tezislə bitir (Bailey, 2018).

Tipik səhv: tədqiqatın əsas problemə keçidi uzadan həddindən artıq geniş və ya qeyri-müəyyən giriş (Read, 2024). Standart kurs və ya buraxılış işində tövsiyə olunan həcm adətən ümumi həcmin **5–10%-i**dir.

:::tip Əlavə
Mühazirənin giriş elementləri sırasında «aktuallıq» sözü müstəqil element kimi yoxdur. Onun rolunu **hook** və **problemin formalaşdırılması** (mövzunun nə üçün vacib olduğu, hansı boşluğun dolduğu) yerinə yetirir. Sual «aktuallıq» sözünü işlədirsə, cavabı bu iki elementə söykə.
:::

### Nəticənin funksiyaları və strukturu

Nəticə girişə simmetrikdir: giriş ümumidən xüsusiyə gedirsə, nəticə **xüsusidən ümumiyə** gedir və konkret nəticələrin daha geniş elmi kontekstlə əlaqəsini göstərir (Короткина, 2020).

Effektiv nəticənin komponentləri:

1. **Əsas arqumentlərin sintezi (təkrarı deyil):** formullar sözbəsöz təkrar olunmur; arqument və sübutların tezisi məcmu şəkildə necə təsdiqlədiyi ümumiləşdirilir.
2. **Əhəmiyyətin göstərilməsi:** nəticələrin sahə, praktika və ya gələcək tədqiqatlar üçün niyə vacib olduğu.
3. **Məhdudiyyətlərin etirafı:** nəticələrin tətbiq sərhədləri dürüst göstərilir; bu, oxucunun müəllifə etimadını (etos) artırır (3-cü mühazirə).
4. **Gələcək tədqiqatların perspektivləri:** açıq qalan suallar və istiqamətlər.

Read (2024) və McCormack və Slaght (2012) iki tipik səhvdən çəkindirirlər: (a) əsas mətndə müzakirə olunmamış **prinsipial yeni məlumat və ya arqument** daxil etmək; (b) girişi sintezsiz, **mexaniki təkrarlamaq**. UNEC qaydaları əlavə olaraq nəticədə girişdə qoyulmuş məqsədə **nail olma dərəcəsinin** göstərilməsini tələb edir.

## İmtahan sualları

:::reveal Yazı prosesinin planlaşdırma, qaralama, yenidən işləmə və redaktə mərhələlərini sadalayın.
Akademik yazı bir dəfəlik köçürmə deyil, idarə olunan və rekursiv prosesdir, və mühazirə onu 3 mərhələ ilə təsvir edir.

1. **Planlaşdırma** (pre-writing): ideyaların toplanması və nizamlanması, planın tərtibi (beyin fırtınası, klaster, 5W1H, ilkin oxu).
2. **Qaralama** (drafting): qaralama variantın tərtibi; qaralama yekun mətn deyil, düşüncə üçün işçi alətdir.
3. **Yenidən işləmə** (revising): mətnin yenidən işlənməsi, arqumentlərin və strukturun dəqiqləşdirilməsi.

**Redaktə** xətti modelin sonuncu addımı kimi verilir (məlumat toplama → plan → yazı → redaktə). Xətti model mərhələləri geri qayıtmadan keçir; rekursiv model isə real təcrübəni əks etdirir: tezis eskizi əlavə oxuya, oxu arqumentlərin dəqiqləşməsinə, bu da strukturun və tezisin yenidən baxışına gətirir. Müəllif yazıdan plana, redaktədən əlavə material toplamağa qayıdır. Yəni redaktə müstəqil son nöqtə deyil, yenidən işləmənin tərkib hissəsi kimi başa düşülür.

Beləliklə, mərhələlər ardıcıl sadalanır, lakin praktikada dövri işləyir. Bu, yetkin yazı təcrübəsinin əsas xüsusiyyətidir və yenidən yazmağı uğursuzluq yox, işin təbii mərhələsi kimi qəbul etməyə imkan verir. Müəllif qaralamanı yekun mətn kimi yox, düşüncə üçün alət kimi görür.
:::

:::reveal İlkin oxu vasitəsilə ideyaların yaradılması, tənqidi təhlil, tədqiqat boşluğunun müəyyən edilməsi və mövzunun daraldılması arasındakı əlaqəni izah edin.
Bu dörd addım tədricən daralan bir yol təşkil edir; mühazirədə bu zəncir bir yerdə adlandırılmasa da, məzmundan belə çıxır.

- **İlkin oxu və açar sözlər.** Terminlər siyahısı və bir neçə mənbənin səthi icmalı tədqiqat sahəsinin sərhədlərini göstərir və ideya toplamaq üçün material verir.
- **Tənqidi seçim.** Texnikaların məhsulu «xam» materialdır; o, sonradan tənqidi seçim və təşkilə məruz qalır. 5W1H geniş assosiasiya dairəsini ən perspektivli istiqamətə daraldır.
- **Boşluğun müəyyən edilməsi.** Mövcud tədqiqatların icmalı ilə biliklərdəki boşluq, ziddiyyət və ya həll olunmamış sual üzə çıxır. Giriş problemi məhz bu boşluq kimi formalaşdırır.
- **Daralma.** Mövzu işin həcmində cavablandırıla biləcək dar tədqiqat sualına, sonra işçi fərziyyə və tezisə çevrilir. Tezis mövcud elmi söhbətə («they say») cavab olaraq qurulur.

Yəni oxu və tənqidi təhlil boşluğu göstərir, boşluq mövzunu daraldır, daralmış mövzu isə tezisin əsasına çevrilir. Nümunə: «Məsafədən iş və əməyin məhsuldarlığı» geniş mövzusu xidmət sferası və 2020–2024-cü illər çərçivəsində dar suala çevrilir. Bu yol xətti deyil: yeni oxu həmişə boşluğun və tezisin dəqiqləşməsinə səbəb ola bilər.
:::

:::reveal Tədqiqat fərziyyəsi ilə mətnin mərkəzi tezisini fərqləndirin.
**Fərziyyə** tədqiqat sualına ehtimal olunan cavab və ya hadisələr arasındakı əlaqə haqqında yoxlanılmalı ilkin müddəadır, **tezis** isə mətnin əsaslandıracağı yekun mövqedir.

- **Xarakter:** fərziyyə ehtimalidir, iş prosesində təsdiqlənə, korrektə edilə və ya təkzib oluna bilər; tezis müəllifin sübutlarla müdafiə etdiyi aydın müddəadır.
- **Sahə:** fərziyyə əsasən empirik və eksperimental tədqiqatlar üçün xarakterikdir; tezis hər akademik mətndə var.
- **Təkamül:** işçi tezis yeni mənbələrlə dəqiqləşir və daralır; fərziyyə yoxlanıldıqdan sonra nəticəsinə görə tezisə çevrilir.
- **Tələb:** fərziyyə yoxlanıla bilən olmalıdır; tezis mövcud elmi söhbətə cavab olmalıdır.
- **Janr:** esse və ədəbiyyat icmalında formal fərziyyə olmur, iş tezis ətrafında qurulur; empirik işdə fərziyyə yoxlanılır, tezis onun nəticəsindən formalaşır.

**Nümunə:** «Məsafədən iş» işində «məhsuldarlığa birmənalı olmayan təsir göstərir» ehtimaldır və yoxlanılır; «azalma əsasən üfüqi koordinasiyanın zəifləməsi ilə bağlıdır» isə məlumat təhlilindən sonra müdafiə olunan yekun tezisdir.

Azərbaycan akademik təcrübəsində girişdə məqsəd, vəzifələr, fərziyyə və müdafiəyə çıxarılan müddəa ayrı-ayrılıqda göstərilir, bu da rəyçilərə və komissiya üzvlərinə işin məntiqi bütövlüyünü girişdən qiymətləndirməyə kömək edir.
:::

:::reveal Dəlillərlə dəstəklənən aydın, fokuslu və müdafiə oluna bilən tezisin formalaşdırılmasının əhəmiyyətini izah edin.
Tezis işin məzmun nüvəsidir; yazı prosesinin ən çox intellektual gərginlik tələb edən mərhələsi ideyalar buludundan fokuslaşdırılmış müddəaya keçiddir.

1. **İstiqamət verir.** Tezis sonrakı oxunu, təhlili və yazını istiqamətləndirir; işçi tezis bu funksiyanı yerinə yetirir.
2. **Fokusluluq.** Yeni mənbələr və arqumentlər tezisi dəqiqləşdirir və daraldır. Tədqiqat sualı da işin həcmində cavablandırıla biləcək qədər dar olmalıdır.
3. **Müdafiə oluna bilmə.** Tezis mövcud elmi söhbətə cavabdır (They Say / I Say). Bu, yetkin akademik mövqeyi əsassız təcrid olunmuş müddəadan fərqləndirir.
4. **Yoxlanıla bilənlik.** Heç bir məlumatla təkzib edilə bilməyən müddəa elmi əsas ola bilməz və çox vaxt konkretlik çatışmazlığını göstərir.
5. **Struktur üçün əsas.** Tezis formalaşandan sonra arqumentlərin və sübutların ardıcıllığı seçilir.

Praktik olaraq tezisin aralıq variantları yazılı saxlanılır və hər mühüm mərhələdən sonra ona qayıdılır. Beləliklə, aydın, fokuslu və sübutlarla əsaslandırılmış tezis oxucuya marşrut verir, mətnin inandırıcılığını artırır və elmi dəyərini müəyyən edir. Nümunə: «məhsuldarlığın azalması əsasən üfüqi koordinasiyanın zəifləməsi ilə bağlıdır» formulu konkret, yoxlanıla bilən və sübutla müdafiə oluna bilən müddəadır.
:::

:::reveal Girişdə mövzunun aktuallığının və tədqiqat məqsədinin, nəticədə isə əsas nəticələrin və elmi töhfənin təqdimatını təsvir edin.
Giriş və nəticə simmetrik funksiyalar yerinə yetirir: giriş ümumidən xüsusiyə, nəticə xüsusidən ümumiyə hərəkət edir.

**Giriş** («qıf» modeli):

- **Hook** oxucunun diqqətini cəlb edir (aktual fakt, statistika, ziddiyyət);
- **Kontekst** mövcud tədqiqatların qısa icmalını verir;
- **Problem** mövzunun niyə vacib olduğunu, yəni biliklərdəki boşluğu göstərir (mühazirədə «aktuallıq» müstəqil addım deyil, bu iki element onun yerini tutur);
- **Məqsəd və vəzifələr** işdə nələrin ediləcəyini bildirir;
- **Tezis** əsas müddəadır və girişin sonunda dəqiq formulə edilir.

**Nəticə:**

- arqumentlərin **sintezi** (təkrar deyil);
- nəticələrin sahə, praktika və gələcək tədqiqatlar üçün **əhəmiyyəti** (elmi töhfə burada ifadə olunur);
- **məhdudiyyətlərin** etirafı;
- **gələcək perspektivlər**.

Nəticə girişdəki məqsədə nail olma dərəcəsini göstərməli, yeni məlumat gətirməməli və girişi mexaniki təkrarlamamalıdır. Giriş oxucunu mövzuya gətirir, nəticə isə işin tapıntısını geniş elmi kontekstə bağlayır. Hər ikisi tezis ətrafında qurulduğu üçün bir-birini tamamlayır və mətnə bütövlük verir. Nümunədə: tapıntı hibrid əmək modelləri üçün əhəmiyyətli, seçim isə xidmət sferası ilə məhdud göstərilir.
:::

### Digər ehtimal olunan suallar

:::reveal Akademik yazıda ideya yaratma texnologiyalarını (klaster və sərbəst yazı daxil) izah edin.
Tezisin formalaşdırılmasına başlamazdan əvvəl ilkin materialı toplamaq və nizamlamaq üçün 5 texnikadan istifadə olunur.

1. **Beyin fırtınası** (brainstorming): bütün ideyalar, assosiasiyalar və suallar qiymət verilmədən qeyd olunur; məqsəd keyfiyyət yox, kəmiyyətdir, tənqid sonraya qalır.
2. **Sərbəst yazı** (freewriting): səhvlərə dayanmadan, məsələn 10 dəqiqə fasiləsiz yazı. Daxili «senzoru» aşır, gözlənilməz fikir dönüşlərini üzə çıxarır.
3. **Klaster / ideya xəritəsi** (mind-mapping): mərkəzdə əsas anlayış, ətrafında alt mövzular və arqumentlər. Əlaqələri göstərir və strukturun qurulmasına kömək edir.
4. **Sual metodu (5W1H):** nə, kim, nə vaxt, harada, niyə, necə sualları problemi sistemli əhatə edir.
5. **Açar sözlər siyahısı və ilkin oxu:** sahənin sərhədlərini müəyyən edir.

Bu texnikaların məhsulu «xam» materialdır; sonra tənqidi seçilir və təşkil olunur. Onların heç biri özlüyündə məqsəd deyil. Nümunə: «Məsafədən iş» mövzusunda beyin fırtınası dağınıq siyahı verir, klaster onu 4 qola bölür (işçi üçün iqtisadi, işəgötürən üçün iqtisadi, psixoloji, təşkilati effektlər), 5W1H ən perspektivli istiqamətə daraldır.
:::

:::reveal Xətti və rekursiv yazı modellərini müqayisə edin.
Hər iki model yazı mərhələlərini (planlaşdırma, qaralama, yenidən işləmə) təsvir edir, lakin onların bir-biri ilə bağlılığını fərqli görür. Fərq məhz mərhələlər arasında geri qayıdışın olub-olmamasındadır.

- **Xətti model:** məlumat toplama → plan → yazı → redaktə, əvvəlki addımlara qayıtmadan. Üstünlüyü: başlanğıc müəlliflərə anlaşılan hərəkət alqoritmi verir. Zəifliyi: real təcrübəni zəif əks etdirir, çünki mövzunun anlaşılması yazı prosesində dərinləşir.
- **Rekursiv model:** yazı dövri prosesdir. Tezisin eskizi əlavə oxuya, oxu arqumentlərin dəqiqləşməsinə, bu isə strukturun, hətta tezisin yenidən baxışına gətirir. «Konspektdən dissertasiyaya» yol bitmiş görünən bölmələrə dəfələrlə qayıtmanı əhatə edir.
- **Psixoloji fərq:** rekursivliyin dərki başlanğıc tədqiqatçının «kamil olmayan» qaralama qarşısında narahatlığını azaldır; yenidən yazmaq uğursuzluq yox, işin təbii mərhələsi sayılır.

Hər ikisi mövzunun anlaşılması dərinləşdikcə yenidən baxışa açıqdır. Mühazirə yetkin yazı təcrübəsinin əsas xüsusiyyəti kimi məhz rekursivliyi göstərir. Praktik nəticə: müəllif planı və tezisi dəyişməyə hazır olmalı, mətnin hər mərhələsini növbəti oxunun və yenidən yazmanın əsası saymalıdır.
:::
