Akademik yazı çox vaxt artıq hazır olan fikrin kağıza bir dəfəlik köçürülməsi kimi qəbul edilir. Yazı prosesi üzərində aparılan müasir tədqiqatlar isə göstərir ki, keyfiyyətli elmi mətn bir dəfəlik hərəkət deyil, geniş həcmli, idarə olunan və əsasən **rekursiv** prosesin nəticəsidir. Bu proses ideyaların yaranmasını, seçilməsini, işçi fərziyyə və tezisin formalaşmasını, habelə gələcək işin məntiqi arxitekturasının qurulmasını əhatə edir (Короткина, 2020).

Yazını məhsul kimi yox, proses kimi anlamaq müəllifin qaralamaya münasibətini dəyişir: qaralama yekun mətn olmaqdan çıxır və düşüncə üçün işçi alətə çevrilir. Bu bacarıqlar materialın xaotik toplanmasından məqsədyönlü və strukturlaşdırılmış şəkildə öz mövqeyini ifadə etməyə keçməyə imkan verir (Bailey, 2018; Read, 2024).

Mühazirə üç qarşılıqlı əlaqəli sahəyə bölünür:

1. yazı prosesinin idarə edilməsi və ideyaların generasiyası texnikaları;
2. gələcək mətnin məzmun nüvəsi kimi tədqiqat fərziyyəsinin və tezisin formalaşdırılması;
3. mətnin məntiqi strukturunun qurulması, giriş və nəticə hissələrinin funksiyaları.

:::tip Əlavə
Mühazirənin ardıcıllığı yazının real ardıcıllığını izləyir: əvvəl **material** (ideyalar), sonra **mərkəz** (fərziyyə və tezis), sonra **forma** (struktur, giriş, nəticə). İmtahanda cavab verərkən bu üç pilləni adlandırmaq cavabı özbaşına siyahıdan çıxarıb məntiqli xəttə çevirir.
:::

## Yazı prosesinin idarə edilməsi və ideyaların generasiyası

### Yazı prosesinin modelləri: xəttidən rekursivə

Akademik yazı prosesi ənənəvi olaraq üç qarşılıqlı əlaqəli mərhələdən ibarət model vasitəsilə təsvir olunur:

1. **Planlaşdırma** (pre-writing)
2. **Qaralama variantın tərtib edilməsi** (drafting)
3. **Mətnin yenidən işlənməsi** (revising)

Vurğulamaq vacibdir ki, bu mərhələlər bir-birini ciddi xətti qaydada izləmir. Təcrübəli müəllif mətnin yazılmasından planın yenidən düşünülməsinə, redaktədən əlavə material toplamağa qayıdır. Rekursivlik yetkin yazı təcrübəsinin əsas xüsusiyyəti hesab olunur (Bailey, 2018; Колесникова, 2019).

| | Xətti model | Rekursiv model |
| --- | --- | --- |
| Ardıcıllıq | Məlumatın toplanması → planın tərtibi → yazılma → redaktə, əvvəlki addımlara qayıtmadan | Dövri proses; mərhələlər arasında dəfələrlə qayıdış |
| Necə işləyir | Hər mərhələ bitir, növbətisinə keçilir | Tezisin qaralama eskizi əlavə oxu tələb edir; oxu arqumentləri dəqiqləşdirir; bu isə strukturun, hətta tezisin yenidən baxışına gətirir |
| Güclü tərəf | Başlanğıc müəlliflər üçün anlaşılan hərəkət alqoritmi | Elmi yazının real təcrübəsini əks etdirir |
| Zəif tərəf | Real təcrübəni zəif əks etdirir: mövzunun anlaşılması yazı prosesində dərinləşir | Müəllifdən «bitmişlik» təsəvvürünü buraxmağı tələb edir |

Колесникова (2019) qeyd edir ki, «konspektdən dissertasiyaya» gedən yol, müəllif materialı daha dərindən dərk etdikcə, artıq bitmiş kimi görünən bölmələrə dəfələrlə qayıtmanı əhatə edir. Prosesin qeyri-xəttiliyinin dərk edilməsi başlanğıc tədqiqatçının «kamil olmayan» qaralama qarşısındakı narahatlığını azaldır və yenidən yazmağı uğursuzluq deyil, işin təbii mərhələsi kimi qəbul etməyə imkan verir.

:::exam
«Yazı prosesinin mərhələlərini sadalayın» tipli sualda mühazirənin **üç** mərhələsini (planlaşdırma, qaralama, yenidən işləmə) adlandır; redaktə isə xətti modelin sonuncu addımı kimi verilir. Mərhələləri sadalamaqla kifayətlənmə: cavabın mütləq **rekursivlik** fikri ilə bitməlidir, çünki mühazirənin əsas tezisi budur.
:::

:::tip Əlavə
Praktikada «yenidən işləmə» iki səviyyəli olur: ilk növbədə **məzmun və struktur** (arqument, ardıcıllıq, tezis), sonra **dil və forma** (üslub, orfoqrafiya, istinadların rəsmiləşdirilməsi). Mühazirədə redaktə xətti modelin addımı kimi göstərilir; belə ayırma həmin addımın nə etdiyini aydınlaşdırır.
:::

### İdeyaların generasiyası texnikaları

Tezisin formalaşdırılmasına başlamazdan əvvəl müəllif düşüncə üçün ilkin materialı toplamalı və nizamlamalıdır. Akademik təcrübədə bunun üçün sınanmış texnikalar istifadə olunur (McCormack və Slaght, 2012; Bailey, 2018; Read, 2024):

:::terms İdeya texnikaları
[[term]]
name = "Beyin fırtınası"
full = "brainstorming"
def = "Mövzu ilə bağlı bütün ideyaların, assosiasiyaların və sualların keyfiyyətinə və uyğunluğuna əvvəlcədən qiymət vermədən sərbəst qeyd edilməsi. Məqsəd keyfiyyət deyil, kəmiyyətdir; tənqidi qiymətləndirmə sonrakı mərhələyə saxlanılır."

[[term]]
name = "Sərbəst yazı"
full = "freewriting"
def = "Orfoqrafiya, üslub və ya səhvlərin düzəlişinə dayanmadan müəyyən vaxt ərzində (məsələn, 10 dəqiqə) fasiləsiz yazı. Daxili «senzoru» aşmağa kömək edir və gələcək arqumentin əsasını təşkil edə biləcək gözlənilməz fikir dönüşlərini üzə çıxarır."

[[term]]
name = "Klaster / ideya xəritəsi"
full = "mind-mapping"
def = "Mövzunun mərkəzi anlayış şəklində və ondan yaranan əlaqəli alt mövzu və arqumentlər şəklində vizual təqdimatı. Fərqli ideyalar arasındakı əlaqələrin aşkar edilməsi və sonradan mətnin məntiqi strukturunun qurulması üçün xüsusilə faydalıdır."

[[term]]
name = "Sual metodu"
full = "5W1H"
def = "Tədqiqat mövzusuna aid «nə? kim? nə vaxt? harada? niyə? necə?» suallarının ardıcıl qoyulması. Problemin müxtəlif tərəflərini sistemli əhatə etməyə və daha dərin araşdırma tələb edən aspektləri müəyyən etməyə imkan verir."

[[term]]
name = "Açar sözlər siyahısı və ilkin oxu"
def = "Mövzuya aid terminlərin siyahısının tərtibi və bir neçə mənbənin səthi icmalı. İşçi fərziyyənin formalaşdırılmasına keçməzdən əvvəl tədqiqat sahəsinin sərhədlərini müəyyən etməyə kömək edir (Read, 2024)."
:::

:::tip Əlavə
Texnikaları **iş rejiminə** görə ayırmaq cavabı güclü edir.

| Texnika | Forma | Nə verir |
| --- | --- | --- |
| Beyin fırtınası | Qısa qeydlər, siyahı | Çoxlu ideya (kəmiyyət) |
| Sərbəst yazı | Fasiləsiz mətn | Gözlənilməz fikirlər, daxili senzorun aşılması |
| Klaster | Vizual sxem | Əlaqələr və gələcək struktur |
| 5W1H | Suallar | Sistemlilik, daralma |
| Açar sözlər, ilkin oxu | Siyahı və icmal | Sahənin sərhədləri |

Beyin fırtınası ilə sərbəst yazını qarışdırma: birincidə ayrı-ayrı ideyalar siyahılanır, ikincidə müəllif fasiləsiz **cümlələrlə** düşünür.
:::

:::example Mühazirədən nümunə
Mövzu: **«Məsafədən iş və əməyin məhsuldarlığı»**.

**Beyin fırtınası** dağınıq siyahı verir: «çevik iş qrafiki», «yol vaxtına qənaət», «komandada kommunikasiya çətinlikləri», «motivasiyanın azalması», «evdə diqqəti yayındıran amillərin çoxalması», «işəgötürən üçün ofis sahələrinə qənaət».

**Klaster** bu siyahını 4 qol ətrafında nizamlayır: işçi üçün iqtisadi effektlər, işəgötürən üçün iqtisadi effektlər, psixoloji effektlər, təşkilati effektlər.

**5W1H** geniş assosiasiya dairəsini daraldır: «Məsafədən işdə konkret olaraq kim məhsuldarlıqda itirir? Niyə? Hansı şəraitdə, əksinə, məhsuldarlıq artır?» Nəticədə ən perspektivli bir istiqamət qalır.
:::

Bu texnikaların heç biri özlüyündə məqsəd deyil: onların məhsulu sonradan tənqidi seçim və təşkilə məruz qalan «xam» materialdır.

:::tip Əlavə
Mühazirədə bu texnikalar məhz fərziyyədən **əvvəlki** mərhələyə aid edilir: onlar ideya toplayır, qərar vermir. Qərar (hansı ideya qalır, hansı atılır) tənqidi təfəkkür işidir; bax: Mühazirə 2 (tənqidi təfəkkür və məntiqi ardıcıllıq).
:::

### Rəqəmsal alətlərdən və süni intellektdən etik istifadə

Müasir akademik yazını süni intellekt əsaslı generativ alətlərin yayılmasından ayrı təsəvvür etmək mümkün deyil. Belə alətlər işin ilkin mərhələlərində (artıq toplanmış ideyaların beyin fırtınası vasitəsilə işlənməsi və ya strukturlaşdırılması, ifadələrin dəqiqləşdirilməsi) faydalı ola bilər, lakin akademik dürüstlük sualları doğurur (Gallant, 2023).

- **Bowen (2024):** yeni dövrdə vəzifə texnologiyaların qadağan edilməsi deyil, onların tətbiqinin **şüurlu və şəffaf** təcrübəsinin formalaşdırılmasıdır. Süni intellekt ideyaların yaranmasında «tərəfdaş» ola bilər, lakin tədqiqatçının öz tənqidi təhlilini və müəllif mövqeyini əvəz etməməlidir.
- **Gallant (2023):** diqqət «köçürməni tutmaq»dan «dürüstlüyə öyrətmək»ə yönəlməlidir, yəni köməkçi alətlərin əlçatanlığından asılı olmayaraq müəllifdə müstəqil düşüncəyə daxili istiqamət formalaşdırılmalıdır.
- **Bergadaà və Peixoto (2024):** akademik dürüstlüyün sərhədləri daim yenidən düşünülməlidir. On il əvvəl ağlasığmaz olan şey (məsələn, mətni yenidən ifadə etmək üçün alqoritmdən istifadə) bu gün köməkçi vasitə ilə müəllif əməyinin əvəzlənməsi arasındakı boz zonada özünü göstərir.

**Praktik nəticə.** İdeyaların generasiyası mərhələsində xarici alətlərdən hər hansı istifadə:

1. **şəffaf** olmalıdır;
2. öz tənqidi düşüncəni **əvəz etməməli, ona əlavə olunmalıdır**;
3. təhsil müəssisəsinin tələblərinə zidd olmamalıdır (mühazirə bu baxımdan UNEC-in dissertasiya yazı qaydalarına işarə edir).

:::tip Əlavə
Bu hissəni cavabda «yazı prosesinin müasir şərtləri» kimi bir cümlə ilə əlavə etmək olar: texnika mənbədir, mövqe isə müəllifindir. Bu cümlə akademik dürüstlük barədə Mühazirə 1 və 6-dakı fikirlərlə (mənbələrlə iş, parafraz) də uyğun gəlir.
:::

### Vaxtın idarə edilməsi və yazıda «tutulma»

Effektiv idarəetmə əsas vaxt bacarıqları tələb edir (Короткина, 2020):

- böyük tapşırığı idarə oluna bilən alt-tapşırıqlara bölmək (məsələn, «planın tərtibi — 30 dəqiqə», «girişin ilk abzasının yazılması — 20 dəqiqə»);
- aralıq son müddətlər müəyyən etmək;
- mütəmadi, «hücumvari» olmayan iş rejimində işləmək.

**Yazıda «tutulma»** (writer's block) müəllifin planlaşdırmadan mətnin yazılmasına keçə bilmədiyi geniş yayılmış vəziyyətdir. Tövsiyə olunan strategiyalar (Read, 2024):

1. «Mükəmməl» ilk cümlə tələbindən müvəqqəti imtina edib **sərbəst yazıya** keçmək;
2. mətni ardıcıllıqla yox, **ən aydın görünən bölmədən** başlayaraq yazmaq;
3. fikir axınını bərpa etmək üçün qısamüddətli olaraq **beyin fırtınasına** qayıtmaq.

Qaralama öz təbiətinə görə kamil deyil; onun sonrakı işlənməsi zəif hazırlığın əlaməti deyil, prosesin ayrılmaz hissəsidir.

:::tip Əlavə
Diqqət et: tutulma strategiyaları ideya texnikalarının **başqa funksiyada** istifadəsidir (sərbəst yazı və beyin fırtınası). İmtahanda «sərbəst yazı nə üçün istifadə olunur?» sualına iki cavab vermək olar: ideya toplamaq və tutulmanı aşmaq.
:::

## Fərziyyə və tezisin formalaşdırılması

İdeyaların generasiyası mərhələsində toplanan materiallar yalnız onlar aydın məzmun mərkəzi, yəni sonradan işin tezisinə çevrilən işçi fərziyyə ətrafında təşkil olunanda tədqiqat dəyəri qazanır. «İdeyalar buludu»ndan fokuslaşdırılmış müddəaya keçid yazı prosesinin, bəlkə də, ən çox intellektual gərginlik tələb edən mərhələsidir (Короткина, 2020).

### Tədqiqat sualından işçi fərziyyəyə

Akademik tədqiqatın başlanğıc nöqtəsi adətən hazır cavab deyil, müəllifin aydınlaşdırmaq, izah etmək və ya sübut etmək istədiyi aydın formalaşdırılmış **tədqiqat sualıdır**. Yaxşı sual işin ayrılmış həcmi çərçivəsində məzmunlu cavab vermək mümkün olacaq qədər **dar**, elmi diqqətə layiq olacaq qədər **əhəmiyyətli** olmalıdır (Bailey, 2018).

Sual əsasında **işçi fərziyyə** formalaşdırılır: qoyulmuş suala ehtimal olunan cavab və ya tədqiq olunan hadisələr arasındakı əlaqənin xarakteri haqqında yoxlanılmalı ilkin fərziyyə. Tezisdən fərqli olaraq fərziyyə:

- əsasən **empirik və eksperimental** tədqiqatlar üçün xarakterikdir;
- öz təbiətinə görə **ehtimalidir**: iş prosesində təsdiqlənə, korrektə edilə və ya təkzib oluna bilər.

UNEC-in dissertasiya işlərinin tərtibi qaydaları tədqiqatın məqsədi, fərziyyə və işin yekun nəticələri arasında aydın fərqin qoyulması zərurətinə birbaşa işarə edir.

:::tip Əlavə
Tipik səhv: **mövzunu** tədqiqat sualı ilə qarışdırmaq. «Məsafədən iş və əməyin məhsuldarlığı» mövzudur: cavab tələb etmir. «…necə təsir göstərib?» isə sualdır: cavab tələb edir və dövr, region, qrup kimi sərhədlərlə daralır. Mövzunu suala çevirmək daralmanın ilk addımıdır.
:::

### Tezisin təkamülü: işçi variantdan yekun formula

Materiala dərindən nüfuz etməzdən əvvəl tərtib edilən ilkin tezis forması **işçi tezis** adlanır. Onun funksiyası müəllifin mövqeyini yekun olaraq təsbit etmək deyil, mətnin sonrakı oxunması, təhlili və yazılması üçün **istiqamət müəyyən etməkdir**. Müəllif yeni mənbələrlə tanış olduqca, fərqli baxışları müqayisə etdikcə və daha inandırıcı arqumentlər aşkar etdikcə işçi tezis təbii şəkildə dəqiqləşir, daralır, hətta prinsipcə yenidən nəzərdən keçirilir (Graff və Birkenstein, 2021).

Graff və Birkenstein (2021) «They Say / I Say» modelində vurğulayırlar: inandırıcı tezis heç vaxt boşluqda formalaşmır. O, həmişə mövcud elmi söhbətə («they say») cavabdır; bu söhbət başqa tədqiqatçılar tərəfindən artıq təsdiqlənmiş, şübhə altına alınmış və ya kifayət qədər öyrənilməmiş məsələlərdən ibarətdir. Tezisin bu **dialoji təbiəti**, yəni əvvəlki tədqiqatlar kontekstində kök salması, yetkin akademik mövqeyi («I say») heç bir əsası olmayan təcrid olunmuş müddəadan fərqləndirir.

Praktik tövsiyə: işin müxtəlif mərhələlərində tezisin aralıq variantlarını yazılı şəkildə qeyd etməkdən çəkinmə və materialın toplanmasının hər mühüm mərhələsindən sonra tezisin formulasına şüurlu şəkildə qayıt. Bu, mövzunun dərk edilməsinin necə dərinləşdiyini izləməyə və tədqiqatın istiqamətini vaxtında korrektə etməyə imkan verir (Короткина, 2020).

:::tip Əlavə
Tezisi mövzudan və faktdan ayır. **Fakt** mübahisə doğurmur (məsələn, «pandemiyadan sonra məsafədən işləyənlərin payı artıb»); **mövzu** cavab vermir; **tezis** isə əsaslandırılmalı və mübahisə oluna bilən mövqedir («azalma əsasən üfüqi koordinasiyanın zəifləməsi ilə bağlıdır»). Bu bölgü Mühazirə 2-dəki arqumentasiya məntiqi ilə (iddia — sübut) də uyğundur.
:::

:::exam
**Yoxlanıla bilənlik meyarı.** Fərziyyə elə formalaşdırılmalıdır ki, toplanan məlumatlar əsasında onun həm təsdiqlənməsi, həm də təkzib edilməsi prinsipcə mümkün olsun. Heç bir empirik məlumatla təkzib edilə bilməyən fərziyyə tədqiqatın elmi əsası ola bilməz və, bir qayda olaraq, formulanın kifayət qədər konkret olmadığına dəlalət edir (Bailey, 2018). «Fərziyyə ilə tezisi fərqləndirin» sualının cavabında bu meyar mütləq olmalıdır.
:::

| Mövzu | Məsafədən iş və əməyin məhsuldarlığı |
| Dəqiqləşdirilmiş tədqiqat sualı | Məsafədən iş formasına keçid 2020–2024-cü illərdə Azərbaycanda xidmət sferası işçilərinin əmək məhsuldarlığına necə təsir göstərib? |
| İşçi fərziyyə (təhlildən əvvəl) | Məsafədən işə keçid əmək məhsuldarlığına birmənalı olmayan təsir göstərir: yüksək özünütəşkilat səviyyəsinə malik işçilər üçün müsbət, daim komanda koordinasiyası tələb edənlər üçün mənfi |
| Yekun tezis (empirik təhlildən sonra) | Azərbaycanın xidmət sferasında məsafədən işdə məhsuldarlığın azalması əsasən işçilər arasında üfüqi koordinasiyanın zəifləməsi ilə bağlıdır, halbuki muxtar tapşırıqlar yerinə yetirən mütəxəssislərin fərdi məhsuldarlığı artır |
:::

Bu nümunə göstərir ki, tezis ümumi mövzudan tədqiqat sualı və yoxlanıla bilən fərziyyə vasitəsilə dəqiq, əsaslandırılmış formulaya qədər necə yol keçir (Короткина, 2020; Bailey, 2018).

### Fərqli iş növlərində fərziyyə, tezis və tədqiqat sualının nisbəti

Bu üçlüyün nisbəti akademik işin janrından və elm sahəsindən asılıdır.

| İş növü | Fərziyyə və tezis |
| --- | --- |
| Analitik esse, ədəbiyyat icmalı | Bir qayda olaraq formal fərziyyə olmur; iş birbaşa tezis ətrafında interpretasiya müddəası kimi qurulur |
| Empirik tədqiqat (eksperimental, statistik, sahə) | Əvvəlcə yoxlanılan fərziyyə formalaşdırılır; yekun tezis onun təsdiqi və ya təkzibi nəticələrinə əsasən formalaşır (Məmmədova, Qasımova, Əyyub, 2014) |

Məmmədova, Qasımova və Əyyub (2014) qeyd edirlər ki, Azərbaycan akademik məkanında buraxılış və ya dissertasiya işinin girişində **tədqiqatın məqsədi, vəzifələri, fərziyyə (əgər tətbiq olunursa) və müdafiəyə çıxarılan yekun müddəa** (tezisin dar mənası) aydın fərqləndirilir. Bu, attestasiya komissiyası üzvlərinə və rəyçilərə işin məntiqi bütövlüyünü girişlə tanışlıq mərhələsində qiymətləndirməyə kömək edir.

:::tip Əlavə
Bu fərqin öz işində tətbiqi: təhlilə yer verəcəksənsə (empirik iş), girişdə fərziyyəni yaz; esse və ya icmal yazırsansa, fərziyyə əvəzinə yalnız aydın tezis ver. Əsas qayda eynidir: oxucu nəyin **yoxlandığını**, nəyin **müdafiə olunduğunu** ayırd edə bilməlidir. Esse və tezis janrları barədə bax: Mühazirə 3.
:::

## Mətnin məntiqi strukturunun qurulması, giriş və nəticə bölmələrinin xüsusiyyətləri

Tezis formalaşdırıldıqdan sonra əsas vəzifə arqumentlərin, sübutların və aralıq nəticələrin təqdim olunacağı ardıcıllığı, yəni mətnin məntiqi arxitekturasını seçmək və ardıcıl həyata keçirməkdir. Yaxşı düşünülmüş struktur həm oxucu, həm də müəllifin özü üçün «yol xəritəsi» rolunu oynayır (McCormack və Slaght, 2012).

### Akademik mətnin arxitekturası: makro- və mikrostruktur

- **Makro səviyyə.** Akademik mətn, janrından asılı olmayaraq, adətən üç blokdan ibarətdir: giriş, əsas hissə, nəticə. APA (2020) bu üçhissəli sxemi empirik elmi məqalələrə tətbiqən **IMRaD** (Introduction — Methods — Results — and Discussion) strukturu kimi konkretləşdirir, bu da materialın təqdimatının vahidliyini və proqnozlaşdırıla bilənliyini təmin edir.
- **Əsas prinsip.** McCormack və Slaght (2012): janrdan (esse, kurs işi, dissertasiya) asılı olmayaraq struktur tədqiqat prosesinin **xronologiyasını deyil, arqumentasiyanın inkişaf məntiqini** əks etdirməlidir. Təqdimatın ardıcıllığını müəllifin materialı hansı sıra ilə topladığı yox, oxucunu tezisin qəbuluna ən inandırıcı və ardıcıl yolla yönəltmək müəyyən edir.
- **Mikro səviyyə.** Ayrı-ayrı abzasların quruluşu və aralarındakı məntiqi bağlar. Bu aspekt 3-cü mühazirədə MEAL modeli (əsas fikir — sübutlar — təhlil — bağlantı) ilə ətraflı nəzərdən keçirilib.
- Makro və mikro **uzlaşdırılmalıdır**: işin ümumi məntiqi hər bölmənin və abzasın ayrılıqda inkişafında izlənməlidir.

:::tip Əlavə
Xronoloji ardıcıllıq ilə məntiqi ardıcıllıq fərqlidir. «Əvvəl A oxudum, sonra B tapdım, sonra C düşündüm» xronologiyadır. Məntiqi struktur isə oxucunun sualına cavab sırasıdır: problem nədir, mövqe nədir, nə ilə sübut olunur, nə nəticə verir. Tədqiqat jurnalı qaralama prosesinin, əsl mətn isə arqumentin xəritəsidir. IMRaD-ın məqalədə necə işlədiyi barədə bax: Mühazirə 4.
:::

### Girişin funksiyaları və strukturu

Giriş 4 qarşılıqlı əlaqəli funksiyanı yerinə yetirir: oxucunun diqqətini mövzuya cəlb edir; zəruri konteksti təqdim edir; problemi və ya mövcud biliklərdəki boşluğu göstərir; işin tezisini təqdim edir. Ən geniş yayılmış model **«qıf»dır** (funnel structure): təqdimat mövzunun ümumi kontekstindən tədricən daralan konkret probleməcən hərəkət edir və tezisin dəqiq formulə edilməsi ilə başa çatır (Bailey, 2018).

Greelane (2023) resursunun tərifinə görə akademik yazı ümumilikdə rəsmiyyət, obyektivlik və sübutlara əsaslanma ilə xarakterizə olunur; giriş bu xüsusiyyətlərin ən aydın görünməli olduğu bölmədir, çünki ilk cümlələr bütün işin tonunu müəyyən edir və oxucuya mövzuya yiyələnmə səviyyəsini nümayiş etdirir.

:::steps Girişin tipik quruluşu (bir qayda olaraq, mütləq deyil)
[[step]]
title = "Diqqəti cəlbetmə (hook)"
body = "Oxucunu sonrakı oxumağa təhrik edən aktual fakt, statistika, qısa nümunə və ya mövcud tədqiqatlardakı ziddiyyətə işarə."

[[step]]
title = "Kontekst və ilkin şərtlər"
body = "Mövzu üzrə artıq məlum olanların, o cümlədən əsas əvvəlki tədqiqatlara istinadların qısa icmalı."

[[step]]
title = "Problemin formalaşdırılması"
body = "Bu işin məşğul olduğu biliklərdəki boşluğun, ziddiyyətin və ya həll olunmamış sualın aydın göstərilməsi."

[[step]]
title = "Tədqiqatın məqsədi və vəzifələri"
body = "Göstərilən problemin həlli üçün işdə məhz nələrin ediləcəyinin qısa təqdimatı."

[[step]]
title = "Tezis"
body = "İşin əsaslandıracağı yekun, aydın formalaşdırılmış müddəa (ətraflı: 3-cü mühazirə)."
:::

Read (2024): başlanğıc müəlliflərin geniş yayılmış səhvi tədqiqatın əsas problemin özünə keçidi uzadan həddindən artıq **geniş və ya qeyri-müəyyən** girişdir. Standart kurs və ya buraxılış işi üçün girişin tövsiyə olunan həcmi adətən mətnin ümumi həcminin **5–10%-i**dir.

:::example Mühazirədən nümunə: «qıf» modelinə görə giriş
1. **Hook:** «COVID-19 pandemiyasından sonra dünya xidmət sferasında daimi məsafədən işləyən işçilərin payı üç dəfədən çox artıb».
2. **Kontekst:** məsafədən işin üstünlükləri və riskləri haqqında mövcud tədqiqatların qısa icmalı.
3. **Problem:** «məsafədən işin fərqli peşə qruplarında məhsuldarlığa müxtəlif istiqamətlərdə təsirini müəyyən edən amillərin nə olduğu hələ aydın deyil».
4. **Məqsəd və vəzifələr.**
5. **Tezis:** yuxarıdakı yekun müddəa.

Ümumi kontekstdən konkret tezisə doğru bu ardıcıl hərəkət «qıf» funksiyasını yerinə yetirir.
:::

:::tip Əlavə
Mühazirənin giriş elementləri sırasında «aktuallıq» sözü müstəqil bənd kimi yoxdur. Mövzunun nə üçün vacib olduğunu **hook** (aktual fakt) və **problemin formalaşdırılması** (biliklərdəki boşluq) göstərir. Praktikada çox vaxt girişi nəticədən **sonra** yenidən yoxlayıb cilalayırlar, çünki rekursiv prosesdə tezis dəqiqləşir. Bu, rekursivlik fikrinin girişə tətbiqidir.
:::

### Nəticənin funksiyaları və strukturu

Nəticə girişə nisbətən **simmetrik** funksiya yerinə yetirir: giriş ümumidən xüsusiyə hərəkət edirsə, nəticə, bir qayda olaraq, **xüsusidən ümumiyə** hərəkət edir və işin konkret nəticələrinin daha geniş elmi kontekstlə necə əlaqələndiyini göstərir (Короткина, 2020).

Effektiv nəticənin komponentləri:

1. **Əsas arqumentlərin sintezi (təkrarı deyil).** Nəticə əsas hissədəki formulları sözbəsöz təkrar etməməli, arqument və sübutların tezisi məcmu şəkildə necə təsdiqlədiyini ümumiləşdirməlidir.
2. **Əldə edilmiş nəticələrin əhəmiyyəti.** Nəticələrin müvafiq bilik sahəsi, praktika və ya gələcək tədqiqatlar üçün niyə vacib olduğunun izahı.
3. **Məhdudiyyətlərin etirafı.** Nəticələrin tətbiq sərhədlərinin dürüst göstərilməsi; 3-cü mühazirədə qeyd olunduğu kimi, bu, oxucunun müəllifə etimadını (etos) artırır.
4. **Gələcək tədqiqatların perspektivləri.** Açıq qalan və gələcək işlərin mövzusu ola biləcək suallar.

Read (2024) və McCormack və Slaght (2012) iki tipik səhvdən çəkindirirlər:

- nəticəyə əsas mətndə **müzakirə olunmamış prinsipial yeni** məlumat və ya arqument daxil etmək;
- girişin məzmunlu sintez olmadan həddindən artıq mexaniki, «formal» **təkrarı**.

UNEC qaydalarında dissertasiya nəticəsinin strukturuna dair tələblər əlavə olaraq nəticədə girişdə qoyulmuş tədqiqat məqsədinə **nail olma dərəcəsinin** aydın göstərilməsini nəzərdə tutur.

:::example Mühazirədən nümunə: nəticənin qurulması
- **Sintez:** «Aparılan təhlil göstərdi ki, məsafədən işdə məhsuldarlığın azalması ilk növbədə üfüqi koordinasiyanın zəifləməsi ilə bağlıdır, halbuki muxtar mütəxəssislərin fərdi məhsuldarlığı artır».
- **Əhəmiyyət:** nəticələrin əmək təşkilinin hibrid modellərinin işlənməsi üçün praktiki əhəmiyyəti.
- **Məhdudiyyətlər:** tədqiqat xidmət sferası ilə məhdudlaşıb, istehsalat sektoruna avtomatik şamil edilə bilməz.
- **Perspektivlər:** gələcək tədqiqat üçün iqtisadiyyatın müxtəlif sahələrinin müqayisəli təhlili.
:::

:::tip Əlavə
Giriş və nəticənin **güzgü** əlaqəsi: girişdəki problem nəticədə həll edilmiş (və ya məhdudiyyətlə birlikdə qismən həll edilmiş) görünməlidir; girişdəki tezis nəticədə sübutlarla ümumiləşdirilməlidir. Oxucu girişi və nəticəni birlikdə oxuyanda işin bütün xəttini tuta bilməlidir. İmtahan cavabında da bu güzgü əlaqəni göstərmək cavabı bütöv edir.
:::

## İmtahan sualları

:::reveal Yazı prosesinin planlaşdırma, qaralama, yenidən işləmə və redaktə mərhələlərini sadalayın.
Akademik yazı bir dəfəlik köçürmə deyil, geniş həcmli, idarə olunan və rekursiv prosesdir; mühazirə onu üç mərhələ ilə təsvir edir və bu mərhələlər bir-birini ciddi xətti qaydada izləmir.

1. **Planlaşdırma** (pre-writing). Müəllif ideyaları toplayır və nizamlayır: beyin fırtınası, sərbəst yazı, klaster, 5W1H, açar sözlər və ilkin oxu. Burada məqsəd tezisin formalaşmasına başlamazdan əvvəl düşüncə üçün xam material hazırlamaq və planı qurmaqdır.
2. **Qaralama** (drafting). Mətnin qaralama variantı tərtib olunur. Qaralama kamil olmaq məcburiyyətində deyil: o, yekun mətn yox, düşüncə üçün işçi alətdir. «Tutulma» halında sərbəst yazıya keçmək və ən aydın bölmədən başlamaq tövsiyə olunur.
3. **Yenidən işləmə** (revising). Mətn yenidən işlənir: arqumentlər dəqiqləşdirilir, struktur və tezis yenidən nəzərdən keçirilir.

**Redaktə** xətti modelin sonuncu addımı kimi göstərilir: məlumatın toplanması → planın tərtibi → yazılma → redaktə. Bu model başlanğıc müəlliflər üçün anlaşılan alqoritm verir, lakin real təcrübəni zəif əks etdirir, çünki mövzunun anlaşılması yazı prosesində dərinləşir.

Rekursiv modelə görə mərhələlər dövri bağlıdır: tezisin qaralama eskizi əlavə oxu tələb edir, oxu arqumentlərin dəqiqləşməsinə, bu isə strukturun və hətta tezisin yenidən baxışına gətirir. Təcrübəli müəllif mətnin yazılmasından planın yenidən düşünülməsinə, redaktədən əlavə material toplamağa qayıdır. Колесникова (2019) göstərir ki, «konspektdən dissertasiyaya» yol bitmiş görünən bölmələrə dəfələrlə qayıtmanı əhatə edir.

Bu fərq praktik əhəmiyyət daşıyır: mərhələləri xətti ardıcıllıq kimi öyrənən müəllif ilk qaralamanı yekun saymağa və düzəlişdən qaçmağa meyl edir, rekursiv yanaşan müəllif isə qaralamanı düşüncə üçün alət kimi görür. Vaxt idarəetməsi də bu prosesə daxildir: böyük tapşırıq alt-tapşırıqlara bölünür və aralıq son müddətlər qoyulur, çünki rekursiv iş planlı olmasa uzana bilər.

Beləliklə, mərhələlər ardıcıl sadalanır (planlaşdırma, qaralama, yenidən işləmə və redaktə), lakin praktikada dövri işləyir; bu rekursivlik yetkin yazı təcrübəsinin əsas xüsusiyyətidir və yenidən yazmağı uğursuzluq deyil, işin təbii mərhələsi edir.
:::

:::reveal İlkin oxu vasitəsilə ideyaların yaradılması, tənqidi təhlil, tədqiqat boşluğunun müəyyən edilməsi və mövzunun daraldılması arasındakı əlaqəni izah edin.
Mühazirə bu dörd anlayışı bir zəncir kimi adlandırmır, lakin onların məzmunu ardıcıl daralma yolunu təşkil edir: oxu və ideya toplama tənqidi seçimə, o boşluğun müəyyən edilməsinə, o da mövzunun daralmasına və tezisə aparır.

1. **İlkin oxu və ideyaların yaradılması.** Açar sözlər siyahısı və bir neçə mənbənin səthi icmalı işçi fərziyyəyə keçməzdən əvvəl tədqiqat sahəsinin sərhədlərini müəyyən etməyə kömək edir. Beyin fırtınası, sərbəst yazı və klaster ideyaların xam materialını verir.
2. **Tənqidi seçim.** Bu texnikaların məhsulu sonradan tənqidi seçim və təşkilə məruz qalan «xam» materialdır. Hansı ideya əhəmiyyətlidir, hansı əsassızdır, qərarını tənqidi təhlil verir. 5W1H geniş assosiasiya dairəsini ən perspektivli istiqamətə daraldır.
3. **Boşluğun müəyyən edilməsi.** Mövcud tədqiqatların tənqidi icmalı biliklərdəki boşluğu, ziddiyyəti və ya həll olunmamış sualı üzə çıxarır. Giriş problemi məhz bu boşluq kimi formalaşdırır. Graff və Birkenstein modelinə görə tezis mövcud elmi söhbətə («they say») cavabdır, yəni boşluq tezisin cavab verdiyi yerdir.
4. **Mövzunun daraldılması.** Geniş mövzu işin həcmində cavablandırıla biləcək dar tədqiqat sualına çevrilir (Bailey, 2018), sual isə yoxlanıla bilən işçi fərziyyəyə və sonra tezisə.

Mühazirənin nümunəsi bu yolu göstərir: «Məsafədən iş və əməyin məhsuldarlığı» geniş mövzusu xidmət sferası və 2020–2024-cü illər çərçivəsində dar suala, ehtimal olunan cavaba (fərziyyəyə) və yekun tezisə çevrilir.

Bu zəncirdə hər pillə növbətisini şərtləndirir: ilkin oxu olmadan boşluğu görmək, boşluq olmadan mövzunu əsaslı daraltmaq, daralma olmadan isə yoxlanıla bilən fərziyyə qurmaq çətindir. Daralmanın meyarı mühazirədə göstərilib: sual işin həcmində cavablandırıla biləcək qədər dar, elmi diqqətə layiq qədər əhəmiyyətli olmalıdır. Əgər boşluq tapılmasa, tezis mövcud söhbətə cavab olmaqdan çıxır və ya təkrara çevrilir.

Bu yol xətti deyil, rekursivdir: yeni oxu boşluğun və tezisin dəqiqləşməsinə, tezis isə əlavə oxuya səbəb olur. Beləliklə, ilkin oxu və tənqidi təhlil boşluğu üzə çıxarır, boşluq mövzunu daraldır, daralmış mövzu isə fokuslu tezisin əsası olur.
:::

:::reveal Tədqiqat fərziyyəsi ilə mətnin mərkəzi tezisini fərqləndirin.
Tədqiqat fərziyyəsi suala ehtimal olunan cavab kimi yoxlanılan ilkin müddəadır, mətnin mərkəzi tezisi isə müəllifin sübutlarla əsaslandırdığı yekun mövqedir.

1. **Mahiyyət.** Fərziyyə qoyulmuş suala ehtimal olunan cavab və ya hadisələr arasındakı əlaqənin xarakteri haqqında yoxlanılmalı ilkin fərziyyədir. Tezis mətnin əsaslandıracağı yekun, aydın formalaşdırılmış müddəadır.
2. **Xarakter.** Fərziyyə ehtimalidir: iş prosesində təsdiqlənə, korrektə edilə və ya təkzib oluna bilər. Tezis isə müəllifin sübutlarla müdafiə etdiyi mövqedir.
3. **Sahə.** Fərziyyə əsasən empirik və eksperimental tədqiqatlar üçün xarakterikdir. Tezis hər akademik mətndə var.
4. **Tələb.** Fərziyyə yoxlanıla bilən olmalıdır: həm təsdiqlənməsi, həm təkzib edilməsi prinsipcə mümkün olmalıdır. Tezis isə mövcud elmi söhbətə cavab olmalı, dəqiq və əsaslandırılmış olmalıdır.
5. **Təkamül.** Tezis işçi variantdan yekun formula doğru dəqiqləşir. Empirik işdə yekun tezis fərziyyənin təsdiqi və ya təkzibi nəticələrinə əsasən formalaşır.
6. **Janr.** Analitik esse və ədəbiyyat icmalında formal fərziyyə olmur, iş birbaşa tezis ətrafında qurulur.

Nümunə: «Məsafədən işə keçid məhsuldarlığa birmənalı olmayan təsir göstərir» ehtimaldır, fərziyyədir; təhlildən sonra «azalma əsasən üfüqi koordinasiyanın zəifləməsi ilə bağlıdır» yekun tezis olur.

UNEC qaydaları və Azərbaycan akademik təcrübəsi (Məmmədova, Qasımova, Əyyub, 2014) girişdə məqsədi, vəzifələri, fərziyyəni və müdafiəyə çıxarılan müddəanı ayrı-ayrılıqda göstərməyi tələb edir ki, rəyçi işin məntiqi bütövlüyünü qiymətləndirə bilsin.

Praktik nümunə: esse yazan müəllif yalnız tezis verir, empirik tədqiqat aparan isə əvvəlcə fərziyyə qoyur, məlumatı təhlil edir və yalnız sonra yekun tezisi formalaşdırır. Mühazirə bu fərqin girişdə də göstərilməsini vacib sayır, çünki oxucu nəyin yoxlandığını, nəyin müdafiə olunduğunu görməlidir.

Funksiyaca fərq belədir: fərziyyə tədqiqatın **qərarsız** mərhələsinə aiddir (cavab hələ bilinmir), tezis isə **qərar verilmiş** mövqedir (cavab sübutla göstərilib). Buna görə fərziyyə təkzib oluna bilər və bu, uğursuzluq sayılmır: təkzib də elmi nəticədir, tezis isə həmin nəticəyə əsasən dəqiqləşir.

Qısaca: fərziyyə yoxlanılır, tezis əsaslandırılır; ilki sualdan, ikincisi tapıntıdan doğur.
:::

:::reveal Dəlillərlə dəstəklənən aydın, fokuslu və müdafiə oluna bilən tezisin formalaşdırılmasının əhəmiyyətini izah edin.
Tezis işin məzmun nüvəsidir: bütün sonrakı oxu, təhlil və struktur onun ətrafında qurulur. İdeyalar buludundan fokuslaşdırılmış müddəaya keçid yazı prosesinin ən çox intellektual gərginlik tələb edən mərhələsidir (Короткина, 2020).

1. **İstiqamət verir.** Hətta işçi tezis mətnin sonrakı oxunması, təhlili və yazılması üçün istiqamət müəyyən edir. Tezis hazır olduqdan sonra arqumentlərin və sübutların ardıcıllığı seçilir.
2. **Fokusluluq.** Yeni mənbələr, müqayisə olunan baxışlar və daha inandırıcı arqumentlər işçi tezisi dəqiqləşdirir və daraldır. Çox geniş və ya qeyri-müəyyən müddəa işin həcmində əsaslandırıla bilməz; eyni məntiqlə tədqiqat sualı da dar olmalıdır.
3. **Müdafiə oluna bilmə.** Graff və Birkenstein (2021): inandırıcı tezis boşluqda yaranmır, mövcud elmi söhbətə cavab verir. Bu dialoji təbiət yetkin akademik mövqeyi əsassız, təcrid olunmuş müddəadan ayırır.
4. **Sübutla dəstək.** Tezis tədqiqatın, sübutların və aralıq nəticələrin ardıcıllığı ilə əsaslandırılır. Nəticə girişdəki məqsədə nail olma dərəcəsini göstərməli və arqumentlərin tezisi məcmu şəkildə necə təsdiqlədiyini ümumiləşdirməlidir.
5. **Yoxlanıla bilənlik.** Fərziyyə dəlilə görə həm təsdiqlənə, həm təkzib oluna bilməlidir; heç bir məlumatla təkzib edilə bilməyən müddəa elmi əsas ola bilməz və konkretlik çatışmazlığını göstərir.

Nümunədə «məsafədən iş» mövzusu tədqiqat sualı və fərziyyə vasitəsilə konkret, sübutla müdafiə oluna bilən tezisə çevrilir: «azalma əsasən üfüqi koordinasiyanın zəifləməsi ilə bağlıdır, muxtar mütəxəssislərin fərdi məhsuldarlığı isə artır».

Eyni zamanda tezis tədqiqatın bütün hissələrini bir-birinə bağlayır: giriş onu təqdim edir, əsas hissə sübut edir, nəticə onun təsdiqini ümumiləşdirir. Tezisi olmayan mətn faktlar toplusuna çevrilir, tezisi çox geniş olan mətn isə fokusunu itirir. Bu baxımdan aydınlıq, dəqiqlik və müdafiə oluna bilmə tezisin keyfiyyət meyarlarıdır.

Praktik olaraq tezisin aralıq variantları yazılı saxlanılır və hər mühüm mərhələdən sonra ona qayıdılır, beləcə tədqiqatın istiqaməti vaxtında düzəldilir. Nəticədə aydın, fokuslu və sübutlarla əsaslandırılmış tezis oxucuya anlaşılan marşrut verir və mətnin inandırıcılığını və elmi dəyərini müəyyən edir.
:::

:::reveal Girişdə mövzunun aktuallığının və tədqiqat məqsədinin, nəticədə isə əsas nəticələrin və elmi töhfənin təqdimatını təsvir edin.
Giriş və nəticə mətnin çərçivəsini təşkil edən simmetrik bölmələrdir: giriş ümumidən xüsusiyə, nəticə xüsusidən ümumiyə hərəkət edir.

**Giriş** (qıf modeli, Bailey, 2018) 4 funksiya yerinə yetirir: diqqəti cəlb edir, kontekst verir, problemi və biliklərdəki boşluğu göstərir, tezisi təqdim edir. Mövzunun nə üçün vacib olduğu (aktuallıq) burada iki element vasitəsilə ifadə olunur:

1. **Hook:** aktual fakt, statistika, qısa nümunə və ya ziddiyyət, məsələn, pandemiyadan sonra məsafədən işləyənlərin payının artması;
2. **Kontekst:** mövzu üzrə məlum olanlar və əvvəlki tədqiqatlar;
3. **Problem:** mövcud biliklərdəki boşluq, ziddiyyət və ya həll olunmamış sual (aktuallığın əsası);
4. **Tədqiqatın məqsədi və vəzifələri:** problemin həlli üçün işdə nələrin ediləcəyi;
5. **Tezis:** əsaslandırılacaq yekun müddəa.

Giriş həddindən geniş olmamalıdır; adətən ümumi həcmin 5–10%-i qədərdir (Read, 2024).

**Nəticə** (Короткина, 2020) aşağıdakı komponentlərdən ibarətdir:

1. **Sintez:** əsas arqumentlərin sözbəsöz təkrarı deyil, tezisi necə təsdiqlədiyinin ümumiləşdirilməsi, yəni əsas nəticələr;
2. **Əhəmiyyət:** nəticələrin sahə, praktika və gələcək tədqiqatlar üçün dəyəri, yəni elmi töhfə və praktiki əhəmiyyət;
3. **Məhdudiyyətlər:** tətbiq sərhədlərinin dürüst göstərilməsi, bu, etosu artırır;
4. **Perspektivlər:** gələcək tədqiqat üçün açıq suallar.

Nəticədə girişdə qoyulmuş məqsədə nail olma dərəcəsi göstərilməlidir (UNEC). İki səhvdən çəkinmək lazımdır: yeni, müzakirə olunmamış məlumat və girişin mexaniki təkrarı.

Mühazirənin nümunəsində girişin tezisi (koordinasiyanın zəifləməsi) nəticədə sintez kimi qayıdır, girişdəki «hansı amillər müəyyən edir» problemi isə nəticədə cavablanır; məhdudiyyət kimi seçimin xidmət sferası ilə məhdud olduğu, perspektiv kimi sahələrin müqayisəli təhlili göstərilir. Yəni giriş və nəticə bir-birinə güzgü kimi uyğunlaşır. Makro səviyyədə bu, IMRaD-dakı Introduction ilə Discussion bölmələrinin uyğunluğuna bənzəyir. Hər ikisi oxucunun işin arqumentasiya xəttini izləməsinə kömək edir.

Beləliklə, giriş problemi və məqsədi qoyur, nəticə isə onlara cavabı və töhfəni verir; birlikdə oxunanda işin bütün məntiqi xətti görünür.
:::

### Digər ehtimal olunan suallar

:::reveal Akademik yazıda ideya yaratma texnologiyalarını (klaster və sərbəst yazı daxil) izah edin.
Tezisin formalaşdırılmasına başlamazdan əvvəl müəllif ilkin materialı toplamalı və nizamlamalıdır; mühazirə bunun üçün 5 sınanmış texnikanı göstərir (McCormack və Slaght, 2012; Bailey, 2018; Read, 2024).

1. **Beyin fırtınası** (brainstorming): mövzu ilə bağlı bütün ideyalar, assosiasiyalar və suallar keyfiyyətinə və uyğunluğuna əvvəlcədən qiymət verilmədən sərbəst qeyd olunur. Məqsəd kəmiyyətdir; tənqidi qiymətləndirmə sonrakı mərhələyə qalır.
2. **Sərbəst yazı** (freewriting): orfoqrafiya, üslub və səhvlərin düzəlişinə dayanmadan müəyyən vaxt ərzində, məsələn, 10 dəqiqə fasiləsiz yazı. Daxili «senzoru» aşır, gələcək arqumentin əsası ola biləcək gözlənilməz fikir dönüşlərini üzə çıxarır.
3. **Klaster / ideya xəritəsi** (mind-mapping): mövzu mərkəzi anlayış və ondan yaranan alt mövzular və arqumentlər şəklində vizual təqdim olunur. İdeyalar arasındakı əlaqələri aşkar edir və mətnin məntiqi strukturunu qurmağa kömək edir.
4. **Sual metodu (5W1H):** nə, kim, nə vaxt, harada, niyə, necə sualları ardıcıl qoyulur; problemi sistemli əhatə edir və daha dərin araşdırma tələb edən aspektləri müəyyən edir.
5. **Açar sözlər siyahısı və ilkin oxu:** terminlər siyahısı və bir neçə mənbənin səthi icmalı tədqiqat sahəsinin sərhədlərini müəyyən edir.

Nümunə: «Məsafədən iş və əməyin məhsuldarlığı» mövzusunda beyin fırtınası dağınıq siyahı verir, klaster onu 4 qola bölür (işçi üçün iqtisadi, işəgötürən üçün iqtisadi, psixoloji və təşkilati effektlər), 5W1H isə ən perspektivli istiqamətə daraldır. Bu texnikaların heç biri özlüyündə məqsəd deyil: onların məhsulu sonradan tənqidi seçilən «xam» materialdır.
:::

:::reveal Xətti və rekursiv yazı modellərini müqayisə edin.
Hər iki model yazı mərhələlərini (planlaşdırma, qaralama, yenidən işləmə) təsvir edir, lakin onların bir-birinə münasibətini fərqli görür: fərq mərhələlər arasında geri qayıdışın olub-olmamasındadır.

1. **Xətti model** məlumatın toplanması → planın tərtibi → yazılma → redaktə mərhələlərinin əvvəlki addımlara qayıtmadan ardıcıl keçilməsini nəzərdə tutur. Üstünlüyü: başlanğıc müəlliflər üçün anlaşılan hərəkət alqoritmi verir. Zəifliyi: elmi yazının real təcrübəsini zəif əks etdirir, çünki mövzunun anlaşılması yazı prosesində dərinləşir.
2. **Rekursiv model** yazını dövri proses kimi görür. Tezisin qaralama eskizi əlavə oxu zərurəti yaradır, oxu arqumentlərin dəqiqləşməsinə, bu isə strukturun, hətta tezisin yenidən nəzərdən keçirilməsinə səbəb olur. Колесникова (2019) göstərir ki, «konspektdən dissertasiyaya» yol bitmiş görünən bölmələrə dəfələrlə qayıtmanı əhatə edir.
3. **Psixoloji fərq.** Qeyri-xəttiliyin dərk edilməsi başlanğıc tədqiqatçının «kamil olmayan» qaralama qarşısındakı narahatlığını azaldır və yenidən yazmağı uğursuzluq deyil, işin təbii mərhələsi kimi qəbul etməyə imkan verir.

Mühazirə rekursivliyi yetkin yazı təcrübəsinin əsas xüsusiyyəti hesab edir. Praktik nəticə: müəllif planı və tezisi dəyişməyə hazır olmalı, hər mərhələni növbəti oxunun və yenidən yazmanın əsası saymalıdır. Başlanğıc üçün xətti model faydalıdır, amma real elmi iş rekursivdir.
:::
