# Fonts

Self-hosted WOFF2 subsets (latin + latin-ext). Every family must contain Azerbaijani ə (U+0259) and Ə (U+018F);
Atkinson Hyperlegible Next was dropped because it has neither. All three families
are licensed under the SIL Open Font License 1.1 (https://openfontlicense.org):

- Inter — The Inter Project Authors (Rasmus Andersson)
- Fraunces — The Fraunces Project Authors (Undercase Type)
- JetBrains Mono — The JetBrains Mono Project Authors
